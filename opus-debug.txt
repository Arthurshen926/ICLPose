 瓶颈根因

 1. Local correlation radius=4 只能处理 ~4px 位移，而 1.4m init 误差在 240x424 分辨率下对应几十到上百像素位移
 2. Learned matcher/flow head 训练时看到的大位移样本，correlation window 里没有正确对应点，于是收敛到预测 zero-flow
 3. 所有 fusion (centroid/consensus) 都失败，因为 top-K 候选质量本身就差
 4. Descriptor-only 训练路线已被多轮实验证伪（peak_acc 始终接近随机）

 战略方向：不要试图一步解决全问题，而是分层组合

 推荐方案：三阶段 Hybrid Pipeline

 Stage 1: Coarse Init (已有)     → 将 init 误差从 ~1.4m 拉到 ~200mm

 Phase 1：让 Learned Refinement 在合理 init 下工作（1-2周）

 Phase 0 给出了一个 geometry-only baseline。Phase 1 目标是让 learned refinement 超过它。

 1a. 扩大 correlation 搜索范围

 问题：radius=4 在 stride-16 特征图上只覆盖 ±64 像素原图位移。从 200mm init 出发可能勉强够用，但从 1m+ 完全不行。

 方案：
 - 实现 multi-scale correlation pyramid（类似 RAFT 的 4 层 pyramid：1/1, 1/2, 1/4, 1/8），每层 radius=4，等效覆盖 ±32 stride-16 像素
 - 或更简单地：先在 coarse feature (下采样 2x-4x) 上做 large-radius correlation 得到 coarse flow，再在 fine feature 上做 guided local correlation
 - coarse_flow_init 路径在 ConcatPoseNet 中已有骨架代码

 关键文件：
 - /root/ICLPose/pose_refine/models/concat_pose_net.py — coarse_flow_init, guided_local_correlation

 1b. 训练 regime 修改

 当前问题：训练时用小扰动（1°/5cm），导致模型只学到 near-zero flow。

 方案：
 - Curriculum perturbation：从大扰动（5°/50cm）逐步退火到小扰动（1°/5cm）
 - 多尺度训练：大扰动时用 coarse correlation，小扰动时用 fine correlation
 - Flow loss masking：已有 query_corr_min_flow_px 参数，忽略 < 1px flow target 避免 zero-flow bias
 - 利用 LoFTR-init 的真实分布训练：不用合成扰动，而是直接用 Stage 1 生成的 init cache 作为训练 init pose（更接近真实测试分布）

 - 现有 GRU mode 支持多步 iteration 但主要在小扰动下训练
 - 改为 unroll 2-3 outer iterations（render → flow → WLS → re-render），让梯度穿过整个 pipeline
 - 第一步用大 correlation 做粗修，后续步骤用小 correlation 做精修
