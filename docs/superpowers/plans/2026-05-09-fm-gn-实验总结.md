# FM-GN (Feature-Metric Gauss-Newton) 实验总结 — 2026-05-08/09

## 背景

Camera Pose Refinement Phase 1 目标：利用 DCFF 渲染的特征图对初始位姿进行优化。核心方法是 Feature-Metric Gauss-Newton (FM-GN)：使用可微特征场的空间梯度，通过 Gauss-Newton 优化直接求解 6-DoF 位姿修正。

公式：**ξ = -(JᵀJ + λI)⁻¹ Jᵀr**，其中 r = F_student - F_DCFF_rendered

关键度量指标：
- **trans_gain**: 平移误差的改善量（正=有帮助），单位 mm
- **grad_cos**: Jᵀr 与真实位姿修正方向 ξ_gt 的余弦相似度（越高越好）
- **map_q_f**: student 特征与 DCFF 特征在 GT 位姿处的余弦相似度（高 ≠ FM-GN 效果好）

## 代码修改

### 1. geometry_solver.py — FM-GN 求解器增强

**文件**: `pose_refine/utils/geometry_solver.py`

新增 `feature_metric_solve()` 参数：
- `rot_damping_multiplier`: 对旋转 DoF 施加不同于平移的阻尼系数，缓解旋转漂移
- `return_Jtr`: 返回 Jᵀr 向量，用于梯度方向损失计算
- `solve_translation_only`: 仅求解前 3 个 DoF（平移），冻结旋转

```python
def feature_metric_solve(
    query_feat, ref_feat, depth, intrinsics,
    damping=1e-3, valid_mask=None,
    rot_damping_multiplier=1.0,       # 新增
    return_Jtr=False,                  # 新增
    solve_translation_only=False,      # 新增
) -> Tuple[torch.Tensor, torch.Tensor]:
```

关键实现：当 `solve_translation_only=True` 时，仅取 JᵀJ 和 Jᵀr 的前 3 维进行求解，旋转 delta 置零。

---

### 2. train_impl.py — 梯度方向损失（V15）

**文件**: `feature_extract/train_impl.py`

新增 `feature_metric_gradient_direction_loss()` 函数（~100 行），核心逻辑：
1. 对 query 和 rendered 特征做 FM-GN 求解，提取 Jᵀr 向量
2. 计算 GT 位姿修正量 ξ_gt = se3_log(T_target · T_current⁻¹)
3. 分别计算平移和旋转的余弦相似度（避免尺度不均衡）
4. 返回 `loss = trans_weight × (1 - cos_trans) + rot_weight × (1 - cos_rot)`

新增配置参数：
```python
"feature_metric_gradient_direction_weight": 0.0,
"feature_metric_gradient_direction_rot_weight": 1.0,
"feature_metric_gradient_direction_trans_weight": 50.0,
```

数据加载条件修复：将 `neg_fine_for_fm` 的加载条件从 `if feature_metric_pose_weight > 0:` 扩展为 `if feature_metric_pose_weight > 0 or feature_metric_gradient_direction_weight > 0:`，避免 V15 中 `UnboundLocalError`。

### 3. eval_per_bucket.py — 评估脚本扩展

## 实验结果

### V4 Fine-only FM-GN（DCFF 冻结，仅在 V4 上做后处理评估）

基准模型：`cpr_baseline_v4`（map_q_f=0.67，无 FM-GN 训练）

|---------|--------|---------------------|-------------------|------------|
| d=0.02 | 0.1°/2.0m | +21 mm | +0.097° | 55% |
| | 0.25°/5.0m | +19 mm | +0.052° | 57% |
| | 0.5°/10.0m | +2 mm | +0.039° | 51% |
| | **总中位** | **+14 mm** | | |
| d=0.05 | 0.1°/2.0m | +27 mm | +0.113° | 57% |
| | 0.25°/5.0m | +25 mm | +0.092° | 54% |
| | 0.5°/10.0m | +9 mm | +0.054° | 54% |
| | **总中位** | **+24 mm** | | |
| d=0.1 | 0.1°/2.0m | +21 mm | +0.097° | 57% |
| | 0.25°/5.0m | +19 mm | +0.078° | 57% |
| | 0.5°/10.0m | +2 mm | +0.039° | 51% |
| | **总中位** | **+14 mm** | | |

**结论**: d=0.05 是最优阻尼，平移增益最大（+24mm 中位）。更低的阻尼增加旋转漂移，更高的阻尼减少增益。平移增益和旋转漂移始终正相关，这是 FM-GN 的根本性 trade-off。

#### 20 次迭代 (d=0.05)

| Bucket | Trans 增益(med/mm) | Rotation 漂移(°) |
|--------|---------------------|-------------------|
| 0.1°/2.0m | +38 mm | **+0.302°** |
| 0.25°/5.0m | +49 mm | +0.221° |
| 0.5°/10.0m | +14 mm | +0.173° |
| **总中位** | **+34 mm** | |

**结论**: 多迭代不收敛——平移增益略增（+24→+34mm），但旋转漂移灾难性放大。最小桶从 0.07° 漂到 0.37°。FM-GN 的梯度方向不指向真实位姿，多步迭代沿错误方向累积误差。

---

#### 仅平移求解 (d=0.05, translation-only)

| Bucket | Trans 增益(med/mm) | Rotation (°) |
|--------|---------------------|--------------|
| 0.1°/2.0m | +12 mm | 0° (固定) |
| 0.25°/5.0m | +6 mm | 0° (固定) |
| 0.5°/10.0m | **-5 mm** | 0° (固定) |
| **总中位** | **+5 mm** | |

**结论**: 冻结旋转会大幅降低平移增益（+24→+5mm）。位姿的旋转和平移自由度高度耦合，限制旋转会阻止优化器找到更好的平移方向。仅平移求解不实用。

### V15 训练（梯度方向损失）

**目的**: 通过直接优化 Jᵀr 与 ξ_gt 的余弦相似度（grad_cos），让特征梯度指向真实位姿修正方向。

**配置**:
- 从 V13 best checkpoint warmstart
- `feature_metric_gradient_direction_weight`: 0.5
- `feature_metric_pose_weight`: 0.0（禁用）
- 12000 steps, LR 7.5e-5
- trans_weight=50.0, rot_weight=1.0（平移 cos 占主导）

**结果**: map_q_f 达到 0.87 (train) / 0.78 (val)，但 **grad_cos 全程平坦在 ~0.48**，没有任何改善。

**失败原因分析**:
1. DCFF 被冻结——梯度方向损失的梯度必须通过 DCFF 渲染器反向传播，但 DCFF 固定不动
2. Student 特征被 RADIO loss 约束（L1 + cosine），梯度方向损失信号被 RADIO 淹没
3. grad_cos 在 0.48 处饱和——可能已达到该架构的上限

---

### V14 训练（单步 FM-GN supervised, 已终止）

**目的**: 用 FM-GN 单步位姿更新与 GT 的误差监督特征学习。

**配置**: feature_metric_pose_weight: 0.15, warmstart from V13

**结果**: 在 step 1820 手动终止——fm_gain 始终为负值（FM-GN 让位姿变差而不是变好）。单步 FM-GN 的梯度噪声太大，无法有效训练。

## 核心发现

### 1. FM-GN 收敛域很窄

有意义的平移增益（>10mm）仅出现在 ≤0.25°/5m 的位姿扰动范围内。在 0.5°/10m 的桶上，增益下降到接近 0 甚至负值。

### 2. 旋转漂移是根本性问题

无论怎么调阻尼和迭代次数，平移增益都伴随着旋转误差的增加。这是因为：
- Jᵀr 与真实位姿修正方向的对齐度 (grad_cos) 仅 ~0.48
- 梯度方向包含大量噪声分量，多步迭代沿噪声方向累积误差

### 3. 通过训练改进 grad_cos 的尝试均未成功

- V14（单步 GN 监督）: fm_gain 从未变正，梯度太嘈杂
- V15（梯度方向损失）: grad_cos 完全平坦，DCFF 冻结阻断了有效梯度流

### 4. map_q_f 与 FM-GN 性能呈反直觉关系

V13（map_q_f=0.76）的 FM-GN 效果比 V4（map_q_f=0.67）更差。更高的余弦相似度不代表特征梯度方向更准确——这两个目标可能是冲突的。

---

## 下一步建议

1. **评估 V15 特征的 FM-GN 性能** — 虽然 grad_cos 没提升，但更高的 map_q_f 可能意外地改善 FM-GN（需要实测验证）

2. **检索辅助初始化** — FM-GN 仅在窄域有效（≤0.25°/5m），需要检索或场景坐标将初始位姿拉入收敛域

3. **联合训练 DCFF + Student** — 解冻 DCFF，让特征场和 Student 共同优化 FM-GN 目标，打通梯度流

4. **粗到精混合策略** — 粗特征做仅平移 FM-GN（大基线），精特征做小范围全 6-DoF FM-GN（精对准）
