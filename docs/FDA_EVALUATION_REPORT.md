# FDA (Featuremetric Direct Alignment) — 评估报告

## 方法概述

FDA 是一种**纯几何、无需训练**的位姿精修方法。核心思想：
- 使用3DGS渲染的特征图（DINO/SD）的空间梯度 + Image Jacobian
- 通过 Gauss-Newton 迭代最小化查询特征与渲染特征之间的L2距离
- 每次迭代：渲染 → 计算特征Jacobian → 求解6×6正规方程 → 更新位姿

## 评估配置
- **场景**: Replica room_0, Seq1
- **数据**: 900帧 (810 train + 90 val)
- **尺度**: fine_dino (768-dim, 35×46)
- **GPU**: RTX 3090
- **深度**: GT深度

## 性能优化日志

### v2 align_fast 优化 (本次实施)
1. **去除 `.item()` CUDA sync**: Normal Eq 从 802ms → 0.6ms (1300×加速)
2. **预缓存 Image Jacobian**: GT depth 不变，只算一次
3. **预 normalize 查询特征**: 每帧一次
4. **Cholesky 求解**: 对 6×6 正定系统
5. **chunk_size=128**: 渲染加速 21.7% (645ms → 506ms/次)
6. **相对收敛早停**: 减少 easy frames 的无效迭代

| 步骤 | 时间 | 占比 |

## 噪声模型分析

⚠️ **重要发现**: "5° noise" 的实际含义

当前噪声模型: `xi[3:6] = torch.randn(3) * 5°` (每个轴独立高斯)

实际旋转角度 $||\omega|| = \sqrt{\omega_x^2 + \omega_y^2 + \omega_z^2}$ 服从 **Chi分布(k=3)**:
- **均值**: ~8.0° (不是 5°!)
- **中位数**: ~7.5°
- **95th 百分位**: ~13.2°
- **99th 百分位**: ~16.1°

这解释了为什么部分帧初始误差 >15°，需要 40+ 次迭代才能收敛。
