# 强遮挡诊断驱动的局部记忆检索、观测选择与高分辨率对应

**结论：取得显著的前端定位改进，尚未取得相对最强主线的最终性能提升。** 原MNN前端50cm/5°召回38.58%，局部锚点提议＋外观多样性采样＋细特征坐标搜索提高到72.60%；对应中位平移误差0.6672m→0.3265m。联合关系分支也明显改善，但没有稳定胜过MNN。强主线v357不替换，最终10cm/25cm/50cm召回仍47.26%/89.73%/95.43%。

完成7个前端族（其中一个是第二PnP随机种子），每族MNN与joint两个控制；每族分别完成区域候选精修、原新对应评分选择、交叉对应库验证、深度验证、分离位姿模式选择。共98组完整438查询位姿输出、490个分片结果文件。它们不是98个独立场景实验。所有失败保留；inf均值表示存在失败，不能只对成功样本计算均值。

## 4. 塔楼样本：补回了区域，尚未解决定位

seq13/frame00142人工诊断轮廓含38个粗token，30个通过MoGe；旧采样保留6个，多样性采样保留19个。旧区域和局部上下文4区域均未包含投影进入轮廓的地图锚点；16区域锚点提议包含此类锚点，补回了该阶段缺口。

全地图108个锚点投影进入轮廓，其中76个通过clean-2DGS渲染深度代理检查。它是地图相关的可见性代理，不是独立物理身份标注。粗RADIO全图搜索中，对每个塔楼token取这些锚点的最高相似度，其全库排名中位数为2；这说明并非所有基础特征都缺少塔楼信号，但不能推导精确像素对应已经正确。

16区域joint分支开始输出塔楼附近的候选对应，但人工轮廓内输出仍无满足4粗像素重投影检查的对应；两随机种子joint都未得到有限区域PnP。MNN虽得到有限位姿，但S0最小平移误差37.55m，S1为82.94m，同样没有恢复。强主线该样本仍17.25m/116.97°。

因此本轮不声称解决了强遮挡：现在已把“塔楼没有进入区域”和“进入后仍无法精确对应”分开。单一全库相似度、局部形状关系及未知阈值还不足以推断可见表面身份，稀小/重复塔楼局部结构、遮挡边界和跨表面关系仍需专门建模。

## 5. 理论解释与尚缺的内容

识别可使用不满足精确深度要求的上下文；位姿测量需要明确世界身份与几何不确定性。将两者分开避免用MoGe可靠性同时代替辨识性、可见性和地图重叠。当前实现只建立了这一职责分离的确定性对照，没有学习成员、区域边界或集合价值。

锚点投票的固定非负权重覆盖目标 F(S)=sum_i w_i 1[存在c属于S使||X_i-c||≤6m] 是单调次模集合函数；代码还施加中心分离约束，因此不能直接引用无约束基数贪心的近似保证。它只是可解释的候选保留机制，不是最优地图或全局定位正确性证明。

查询相对未知阈值使低绝对相似度但相对最优的局部证据有机会保留；它也可能接受“全库都不合适”的赢家，所以不是概率校准或真实重叠预测。全库均值/标准差标准化也不能自动获得跨场景置信度。

MoGe深度检查是候选相机下的辅助一致性验证，不等于前景分割、实例识别或精确遮挡推理；尺度拟合仍可能被错误对应污染。未实现学习的候选条件重叠掩码、遮挡边界不确定性传播、上下文/测量双成员联合学习。

局部关系仍未稳定胜过MNN。相机侧的树冠邻接关系可能与地图建筑成员无关；图像近邻边也可能跨越遮挡深度边界。当前共同关系尚未解决身份、可见性和几何兼容性的联合估计，不应将其包装成完整的仿生认知地图。

## 6. 实验边界、成本和验证

全部438查询仍是StMarysChurch的seq10和seq13，五个分片不是五个场景。这些路线已多轮用于开发；本轮架构诊断也受该样本观察启发。推理代码不读取query GT，不能据此宣称评估集从未参与研究选择。尚无新场景、冻结确认集、学习地图两组完整实验或顶刊领先鲁棒性证据。

4区域每区域最多250个评分假设；16区域每区域62个，总上限992。实际有效假设量不同，例如16区域S0平均MNN690.92、joint473.35。更大候选库、全库特征搜索、更多候选精修和验证都增加成本；这些缓存实验没有证明相同RGB到pose成本上的优势。部分旧timing.json的scope字符串仍写“四个控制”，本轮命令实际只运行MNN/joint两种，应以保存的command.json与输出臂为准。

33项相关测试通过，覆盖少量外观保留、无效测量排除、局部区域识别、真实地图身份保留、深度奇偶校验、每query未知阈值、位姿模式分离，以及既有关系不变性、直接特征精修与回退。490文件数组哈希、元数据哈希、刚体位姿均通过；350个带回退文件验证未接受查询逐元素等于强基线。旧前端88查询兼容性复跑中MNN/joint位姿与v367逐元素一致（含失败）。这些检查支持实现合同，不能代替泛化实验。

前端MNN锚点提议对旧MNN的50cm提升34.02个百分点；开发集配对query bootstrap描述区间为[28.76,39.27]个百分点。该区间不计多轮方法选择或路线相关性，只用于描述当前查询集合，不是泛化置信区间。

## 7. 下一阶段优先级

1. 用此前准备的路线排除建图监督，学习局部识别/重叠与明确地图身份；包含实际检索混淆、遮挡未知和小区域正例，避免继续只调统一阈值。
2. 让关系图尊重遮挡边界，并区分上下文联系与可参与PnP的测量关系；检验为何joint会丢掉MNN仍保留的机会。
3. 将候选验证训练目标对齐最终位姿风险和连续测量目标，冻结后再做独立路线/场景确认；当前交叉库重投影分数并不够。
4. 学习真正的上下文与测量成员，并重编码描述和对应；目前仍是固定半径地图，不属于已完成可学习地图单元。
