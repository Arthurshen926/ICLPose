# v414：真实强端点局部监督与粗细特征共同确认

## 结论

完成真实 mapping v357 端点上的局部候选生成、保留 token 证据重建、监督构造、训练与校准，以及 438 条 query、两种子的完整对照。粗细特征共同改善的规则带来小幅净收益：两种子 10cm/25cm 召回各增加 0.228 个百分点，50cm 不变，位置中位误差降至 0.104474m。不是大幅突破，也不是逐例无损；不自动替换默认主线。

## 本轮真正落实的内容

1. 从 v413 已封存的七条 mapping 路线 v357 端点出发，各产生普通、鲁棒两种 stage-followup 正则化精修候选。query 也从同样的 v357 端点产生同样两种更新，不再用普通 PnP 候选之间的比较充当强端点精度训练对。
2. 重建 mapping/query 验证 bank：排除原始三套对应的 query token、v344/v357 和本轮候选实际选择的 token，以及投影结构和深度验证中 structure_guarded 使用的中心 token；再用冻结阈值和全局 MNN 构造对应。mapping 的实际 prototype 来源排除伪查询所属路线。
3. 先冻结无标签局部对和来源哈希，再加载 mapping 位姿标签。拟合使用 seq1/2/4/6，校准 seq7，确认 seq8/11；query 标签未参与训练和校准。反向对仅作为拟合增强，校准只评估从实际强端点出发的正向决策。
4. 部署时保留 v413 dual_support 鲁棒端点，只有该位姿与 v357 初始化逐数组完全相同时才允许应用本轮局部更新，防止局部模块覆盖已修复的不同位置假设。

“保留”只指中心 token 身份排除，不能保证插值邻域、编码器感受野或场景几何独立。并且 coarse/fine 都来自同一基础模型，不能把两者相乘解释为独立概率。

## 监督定义的真实问题

旧 v409 学习器只使用归一化位姿误差相对变化至少 25% 的训练对。本轮实际强端点更新没有训练对满足该门槛。最初训练因此暴露空训练集分支；已修复为显式禁用并输出原因，固定 margin 对照重新运行完成，未通过调整 query 门槛强行训练。

进一步训练连续增益回归器，目标为 u=max(t/0.1,r)，g=(u_base-u_candidate)/max(u_base,u_candidate,1e-12)。使用粗/细保留支持上的 12 维成对差分，带标准化的零截距 Ridge(alpha=1)，按 query 平衡权重；对调候选时特征和监督同时反号。输出为有符号效用增益，不是概率。

共使用 312 个有向拟合例子，含反向增强，不是 312 条独立图像。seq7 在非负预测增益门槛下满足至少五条不同 query、无观察到的 10/25/50cm 阈值损失；seq8 确认仍出现阈值损失，因此没有风险保证。映射监督定义修正并不意味着该线性模型足够表达真实位姿收益。

## 同一冻结候选与证据上的对照

- plain / robust：不使用学习器，直接应用对应类型的局部更新，仅受精修及实际 base 绑定约束。
- learned：连续增益回归器选择通过校准门槛且支持充分的候选。
- fine_mean：仅要求保留支持上的细特征平均余弦相似度严格改善。
- agreement：粗、细特征平均余弦相似度都严格改善，在合格者中按细特征改善量选择；无新增拟合参数或扫描的数值阈值。该对照是在上述开发结果暴露问题后提出，不能称为预注册实验。

重复精修不能无条件接受：plain 在两种子都使 10cm 召回降至 46.119%，25cm 也下降。learned 略微降低位置/旋转均值，却把 10cm 召回降至 46.804%，没有稳定优于简单规则。fine_mean 提升 25cm，但牺牲部分 10cm。agreement 在这轮比较中兼顾了净 10cm/25cm 收益，仍存在局部退化。

agreement 的阈值分解在两组种子一致：10cm 收益率 0.684932%、损失率 0.456621%，净增 0.228311 个百分点；25cm 收益率 0.228311%、损失率 0%；50cm 无变化。不能把净召回提升描述为没有误切换。

具体 10cm 退化：seq10 frame00042 从 0.097705→0.100549m；seq13 frame00266 从 0.091418→0.100334m。它们说明描述符多尺度一致性不是位姿风险证书，阈值附近的小幅更新仍需更好的风险判断。

两种子不是独立样本。此处同一 v357 局部更新应用于两条不同鲁棒端点分支，大部分相同 base 上的更新一致，不能据此推断统计显著或跨场景泛化。

## Mapping 确认与仍存在的不足

agreement 在 seq7/8/11 的该批确认例中未出现主要阈值损失，但 seq8 平均位置误差 0.137594→0.139120m、中位数 0.120595→0.126187m，说明“无阈值损失”不等于误差全面改善。seq11 平均位置误差仍约 9.95m，大量查询不属于局部精度问题；不能混在一起推导定位已正确时的精度风险。

这些 mapping 路线共享场景几何、冻结历史学习器，且已在多轮研发中查看；确认是拟合路线分离，不是新的封存测试。全局 MNN bank 的读取/匹配以及两次局部优化增加了计算量；没有声称与 v413 等时或端到端延迟改善。

塔尖 frame00142 没有新增真实可见对应，仍未解决。局部精修不能修复错误位置假设；本轮正是通过 base 绑定限制它影响鲁棒分支。

## 验证与附件状态

96 项相关测试通过，覆盖显式弃权拒绝饱和分数、校准不能用同一 query 的多个候选凑样本量、各级阈值损失、粗细资格过滤后再排名。对全部 140 mapping 和 438 query 核对 bank 数组/地图绑定、保留中心 token 与排除集合不相交、初始化/候选来源哈希一致。git diff --check 通过。

完整 mapping v357 重放在 v413 完成；本轮进一步落实实际局部更新监督、连续效用训练和冻结 query 实验。D 已有真实训练与评估结论，但学习器尚未优于规则。A 归一化互选保持已修复；B 人工核验的可见塔尖支持、C 稳定有效的新观测仍未完成，附件尚未全部解决。

下一步精度侧应研究局部更新幅度与风险，重点是接近召回边界时的误差增加，而不是继续使用大幅相对改善标签或只扩大学习器。鲁棒侧仍须取得强遮挡下新的真实可见对应。当前结果支持多尺度证据有互补价值，但还不足以证明整体方法已理论完备或构成顶刊级新颖性。
