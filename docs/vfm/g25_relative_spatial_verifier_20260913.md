# v404：从绝对成功分类改为相对候选比较

本轮继续处理遮挡下的支撑可信度与位姿选择。结果根目录为 `output/g25_pose_transport/planar_map_rendered_ransac_v1/surface_coordinate_upgrade_v1/spatial_verifier_v404`，下文简称 R。

## 结论与采用边界

本轮取得了两种子均出现的最终尾部误差改善：MNN 候选池的相对空间验证器，使平移均值从强基线 0.697 m 降至 0.262/0.266 m，旋转均值从 1.820° 降至 0.908/0.840°。平移中位数保持约 0.108 m，10 cm/1° 召回保持 47.26%。这次不是只改善中间分数或只保留成功样本。

但 25 cm 召回仍略降，50 cm 在种子1略降、种子2持平。因此把它保留为有实际尾部收益的研究分支，不替换原强基线，不声称遮挡问题全部解决或严格召回全面突破。塔尖 frame00142 仍未恢复正确定位。

## 1. 新增了什么

`spatial_pose_evidence.py` 从同一查询的共同对应集合计算候选证据：唯一 token 支撑比例、截断重投影残差、16×16 coarse-image 像素网格的覆盖和饱和支撑、凸包面积、深度分布，以及局部位姿 Jacobian 的条件性和单位像素噪声下的平移线性化敏感度。

同 token 的重复候选先规范化去重，一个 token 只按最佳重投影对应计票；空间网格内使用最大残差质量而非直接累加。它仍不能保证不同 token 是统计独立观测，也未单独处理所有重复物理锚点。

Jacobian 在当前相机坐标下对局部位姿扰动求导，避免绝对世界坐标原点改变旋转/平移耦合量。单位像素噪声下的逆信息矩阵只是诊断特征，**不是经过测量噪声标定的位姿后验协方差**。几何退化时使用大敏感度标记；测试覆盖世界原点平移不变性、等数量集中/分散支撑及重复候选不增加证据。

模型保持 RADIO、MoGe、度量地图、MNN 身份、候选生成及精修冻结，仅学习如何比较已有候选。本轮未新增 RGB 特征提取、地图成员学习或坐标回归头。

## 2. mapping 数据与监督隔离

使用 v402 已冻结的实际 LoD 区域提案，并对每个 mapping query 排除所属路线的地图成员。重新生成相同 MNN、细网格对应和最多250假设/区域的候选，再做相同的两阶段精修。每条路线的全部候选位姿与证据先写入 `*_unlabelled.json`，之后才读取该路线的 GT 标注。

七条 mapping 路线共970个原始/精修候选。seq1/2/4/6 的560个候选用于训练；seq7用于校准；seq8/11用于头级保留验证。原始候选和精修结果、同一查询内的候选高度相关，因此训练按查询平衡权重，不能把970个候选当970个独立样本。路线排除不等于重新独立重建地图，仍共享场景几何和已有特征。

测试查询 seq10/seq13 不参与模型训练或阈值标定。完整评估仍是438个反复用于开发的查询，不是新的独立测试集。R 内冻结快照哈希均已复核。

## 3. 绝对成功验证器：已实施，但没有净收益

先训练标准化后的正则 logistic 模型，预测候选是否满足0.5 m/5°。seq7校准分数后，按“至少接受5个查询且样本精确率≥95%”选择阈值。校准集实际精确率不等于统计置信度保证，更不等于部署风险保证。

seq8接受率60%，seq11仅5%，这些接受结果在各自小样本中均正确；seq11实际上只有极少支持，不能据此声称100%可靠。四组查询候选池上的最终平移均值约0.698–0.701 m，没有改善强基线；严格召回还有小幅回退。

原因之一是任务不一致：一个候选即使没有达到0.5 m，也可能显著优于几十米错误的当前位姿。绝对成功分类难以表达这种改进价值。它也没有解决当前位姿与新候选证据分布不同的问题。

## 4. 相对候选比较：实际收益所在

对同一 mapping query 的候选对，以

\[
 e(T)=\max(\|\Delta t\|/0.5,\;\Delta\theta/5)
\]

作为离线监督质量，只有误差比至少1.25的候选对参与训练，避免把近似等价解的细小差异当可靠排序标签。输入为证据差值；正反方向成对，模型无截距，按查询平衡权重。训练共3016个有向候选对，但独立单位仍是查询。

决策形式为

\[
P(T_a\succ T_b)=\sigma\bigl(\alpha w^\top D^{-1}[f(T_a)-f(T_b)]\bigr).
\]

这消除了同一查询内不变的难度特征，但不保证剩余特征因果有效。seq7标定正尺度及接受阈值；阈值要求mapping成对精确率≥95%且至少20个有向候选对。它是有限样本操作点，不能解释为95%部署正确率；成对数据相关，校准也不是对完整最终决策的风险保证。

实际推理比较基线与每个保留的精修区域候选，选择预测相对质量最高者；通过阈值且相对基线位移>0.5 m或旋转>3°时才替换，否则逐位保留基线。该模式分离规则沿用既有方法，不根据测试误差调整。

相对模型mapping保留验证的成对准确率：seq8为92.48%，seq11为82.41%；接受候选对精确率分别93.79%、82.58%。所以这不是跨条件已经校准好的置信度模型，seq11明确暴露了泛化缺口。

## 6. 空间/几何特征是否真的贡献收益

在相同候选、标签、训练/校准路线和模型复杂度控制下，将空间覆盖、凸包、深度分布、条件性、噪声敏感度和空间饱和支撑通道置零，保留token数量、支撑比例与残差。每个模型按同一校准准则确定自己的操作点。

|MNN候选池|平移均值，种子1/2 m|25cm召回，种子1/2|50cm召回，种子1/2|
|---|---:|---:|---:|
|仅支撑/残差相对模型|0.436 / 0.534|88.81% / 88.81%|94.52% / 94.75%|
|完整空间/几何相对模型|0.262 / 0.266|89.27% / 89.50%|94.98% / 95.43%|

这支持这组新增证据在当前查询上的整体价值，不能分离每一通道的独立贡献，也不是理论充分性证明。反例同样保留：mapping seq11中，仅支撑/残差模型的成对准确率91.68%、接受精确率92.68%，高于完整模型。完整模型对单位噪声敏感度的学习系数也没有物理单调性保证，因此不能直接把它解释为真实不确定性。

## 7. 候选池上限与仍然存在的问题

事后GT诊断，在“原基线＋全部已保留精修区域候选”中按每个召回阈值理想选优，MNN两种子上限分别为：10cm约60.96/60.27%，25cm均93.61%，50cm约96.35/96.58%。这是不可用于推理的oracle，不是可实现定位成绩；不同阈值可选择不同候选。

这说明当前池内仍有选择空间，尤其是细精度；但模式分离保护和粗粒度相对误差监督尚未允许可靠利用这些细改进。它不保证学习器能达到oracle，也不能从候选池上限推出所有场景都能成功。

优先未完成项：

1. 为相对替换决策建立真正按查询校准的风险控制，同时考虑基线正确时的损害，不能把成对精确率当最终决策精确率。
2. 改进共享区域/物理身份监督和少量支撑的可观测性；当前验证器只能重排已有候选，无法挽救候选池完全缺失的塔尖案例。
3. 将单位噪声几何特征升级为带可靠测量噪声的约束，并验证世界/图像重复支撑相关性；本轮未训练真实不确定性头或信息增益支撑选择器。
4. 独立路线条件及独立场景验证。本轮仍是共享场景mapping头级保留集加开发查询，不满足顶刊关于全面鲁棒性、泛化与最终置信度的完整证据要求。

## 8. 实现与复现

核心文件：`spatial_pose_evidence.py`、`build_mapping_spatial_verifier.py`、`train_absolute_spatial_verifier.py`、`train_pairwise_spatial_verifier.py`、两个 `apply_*_spatial_verifier.py`。R/reproducers保留实际调度、消融、评估和报告脚本，R/sources保留代码快照。路径当前绑定项目现有缓存布局；重跑应使用新输出目录，不能覆盖既有正式结果。

`summary.json`、`metrics_table.md`保存全部12组最终输出指标；`completion_audit.json`覆盖60个位姿文件，确认查询集合一致、全部有效旋转及未接受候选时精确回退。12组含候选池/种子/消融，不是12项独立场景实验。训练前冻结快照哈希全部复核。

相关测试35项通过，包含新增四项证据性质测试；源码编译与diff检查通过。未修改第三方子模块，未将新分支自动替换为默认方法。
