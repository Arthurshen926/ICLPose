# G25：完整真实输入与局部上下文记忆

## 方法边界

本轮优先验证附件的前两级假设：完整真实输入，以及不改变候选/坐标的固定上下文。尚未实现可学习地图单元选择、高分辨率 RADIO 读出或新的 MoGe 相对形状头；不能把这些计划写成已完成的方法贡献。默认定位配置不变。

底层地图固定为可信米制表面 G。记忆单元 m=(S_m,C_m,A_m)：S_m 是一个或多个真实表面片段的引用，C_m 是识别上下文，A_m 是匿名外观模式。跨表面组合不合并法向、UV 或三维坐标。在线候选身份由外观和局部关系判断，几何测量仍使用原始表面及投影模型。

候选记忆集合可先由固定 chart、子区域和邻接组合构造。待固定上下文通过验证后，学习选择策略 s，目标为在建图留出视图上最小化位姿损失加失败代价，并满足地图字节和在线计算预算。评估路线不得参与 s 的拟合。区域尺度和表面组合可以变化，几何本身不能随 query 变形。

观测必须按独立 query token 计数：重叠记忆引用同一 token 时，应先聚合该 token 的多个解释，再向几何目标贡献一次支持。局部信息矩阵 JᵀWJ 只能描述给定正确关联附近的可观测性，不能证明身份正确；因此不能只最大化法向跨度或 log determinant。

监督有效性 V 与可见视觉输入 X 分开。训练目标 E[V·loss]/E[V] 只描述可监督条件人口。缺失标签与场景内容相关，不能假设 missing-at-random，不能将这个条件概率解释为所有真实输入的正确率。扩大 X 的覆盖率也不保证位姿损失下降。

## 已实现

`audit_goal_maplet_mapping_crossplane_retrieval` 新增 `--radio_manifest`：从完整 MoGe 文件清单读取 held route，读取并校验完整 36×64 RADIO；即使一张图完全没有 mapping 观测，也进入候选生成。区域至少四个 token 的门限与原匹配原语一致。完整输入不受监督位置和监督是否存在影响。

先冻结召回与 MNN/homography 候选，再附加监督。标签为正例 1、负例 0、歧义 -1、未知 -2，另存 `supervision_available` 与 `supervision_valid`。同 token 多个监督位置的冲突按两两直径判断，修复仅比较第一个位置可能遗漏两端冲突的缺口。unknown 不进入负例训练，也不算作已知跨平面错误。

`--context_radius 2` 为第一版固定上下文：在地图建图视图和 query 上分别取实际 token 支撑外的两格邻域，读取完整 RADIO。上下文可以跨平面，但不生成新的几何观测。分别保存局部/上下文读出，不平均成同一个坐标特征。每个候选平面先按原局部相似度选择匿名视角模式，再读取该模式的纯上下文相似度，避免把新增局部余弦信息误认为上下文增益。它只增加一个关联特征，不改变原 Top-10、MNN、homography、坐标、候选数量。

该上下文仍是源视图上提取后匿名聚合的外观模式，不是已学得的自适应地图，也没有消除源视角相关性。固定二维邻域不具备跨视角尺度不变性，空邻域以零向量表达。没有针对评估标签调整半径。

关联对照使用原五参数 logistic 与增加上下文的六参数 logistic，固定 L2=0.001，49 图 fit /49 图 eval。训练分图且按独立 token/图像平衡；评价仍是已知且非歧义候选上的条件指标，不是完整定位指标。新增候选不变性审计入口验证所有原数组、前四维分数及监督逐项相同。

## 理论依据与后续判据

RADIO 当前值得检验的是上下文身份信息与精细坐标信息是否需要分开读取，而不是抽象地声称“未发挥全部能力”。高分辨率必须真的增加有效视觉输入，并保证地图/query 合同一致。官方实现支持多分辨率和中间层接口，但接口可用不证明本 checkpoint 的定位增益：[RADIO 官方仓库](https://github.com/NVlabs/RADIO)。

MoGe 下一阶段可提供相对法向、遮挡顺序和归一化局部形状的软兼容分数。法向夹角可消除共同旋转影响，距离比可消除共同乘法尺度，但不能消除局部形变；可靠度需要验证。此轮没有修改 MoGe 几何或其精修器。

仿生叙述限于“受稳定地标锚定与上下文空间记忆启发”。人类 fMRI 发现 RSC 对永久性地标具有选择性反应，支持重视稳定地标的设计动机，不证明稀疏区域地图、6DoF 求解器或本方法优越性：[Auger 等，PLOS ONE 2012](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0043620)。本轮未以仿生叙述替代消融证据。

若固定上下文只改善标定，下一步应检查重复结构上的身份排序和固定预算正确初值产生率；若排序也不改善，不直接训练更复杂的区域生成器。只有同预算固定后端定位对照改善，再进入多尺度建图选择，并在未参与拟合的路线/场景检验。当前正式基线仍是既有正确性修复后的 96/330/398/409/412，本轮候选探针结果不能与之相加。

## 解释限制

这里的完整输入指真实 MoGe 区域内的全部有效 token，而不是已将平面外所有像素变成几何观测。3095 个真实区域中仍有 7 个不足四个 token，按原匹配门限不进入实验。地图侧邻域以已有 mapping token 支撑为起点，可能包含同平面空隙，也可能跨表面；它不等价于边界与尺度已经对齐的三维局部记忆。这一版失败只能约束固定二维邻域读出，不能否定结构化跨表面记忆。

上下文探针没有改变位姿后端，因此单凭分数对照不能宣称位姿提升。该实验也未完成相同地图字节/墙钟预算比较。新特征的提取成本与现有匿名模式数量有关，不能声称零开销。

v216/v217 和 context-v218 保留为开发产物。v217 的混合局部/上下文分数包含额外局部余弦，不能单独归因于上下文；正式对照采用 v218 完整输入控制与 v219 纯上下文读出，后者绑定源文件哈希和完整命令。

## 本轮实测结果

98 张 seq9 建图留出图；整条 seq9 从地图外观原型构造中排除。仍是已有开发路线，不是新场景盲测。正式完整输入控制 v218 与早期 v216 的候选文件及标签文件哈希分别完全相同，说明完整文件清单处理与两两冲突修复没有改变这批数据的结果。

| 人口/指标 | 旧监督子集 v214 | 完整真实输入 v218 |
|---|---:|---:|
| 进入召回的区域 | 1616 | 3088 |
| homography 后候选行 | 50867 | 102379 |
| 可靠正例行 | 5417 | 5350 |
| 可靠负例行 | 13811 | 11556 |
| 歧义行 | 31639 | 29567 |

完整输入有 138448 个区域/token 引用，其中 46591 个有 mapping 支撑；重叠区域的引用数不能与旧审计的 134805 个独立图像/token 混用。匹配后 55906 条 unknown 对应 34443 个独立图像/token，均未进入负样本训练。

完整输入增加了实际候选覆盖，却未增加已知正例支持。新增 unknown 会参与 MNN 竞争，因此已知正例变化不能单独代表全部真实匹配质量，也不能把 unknown 全部解释为有用信息。此次结果不支持“补齐输入就自动提高精度”。

固定完整候选池，8537 条 eval 已知非歧义候选：

| 关联读出 | AUC ↑ | Brier ↓ | BCE ↓ |
|---|---:|---:|---:|
| 余弦单特征标定 | 0.948142 | 0.106630 | 0.355951 |
| 原五参数探针 | 0.947470 | 0.087897 | 0.298514 |
| 加纯上下文，六参数 | 0.947551 | 0.087575 | 0.297666 |

上下文相对五参数只有极小改善，AUC 仍未超过原余弦。49 张评价图中 31 张 BCE 改善；逐图等权平均 BCE 变化 -0.000183，10 图循环分块 bootstrap 区间 [-0.001761,+0.001795]，跨零。相邻图像与已知标签子集限制仍然存在。

**结论：完整输入合同修复保留；当前两格固定上下文只能视为微弱标定信号，不升级默认、不宣称位姿增益。没有继续按这批评估结果扫半径、换 backbone 或训练任意地图单元。** 下一阶段应优先补全输入上的独立几何监督与结构化消歧证据，再决定多尺度选择是否值得做。单个邻域均值仍可能丢掉“墙角在窗户哪一侧”的关系，不能把此结果外推成 RADIO 已无剩余信息。

候选不变性审计通过：所有候选身份、token、三维原型、召回排名、homography keep、原四维关联特征、监督数组逐项完全相同。上下文仅增加第五维输入分数。本轮没有执行完整 query 位姿重放，正式定位基线不更新。
