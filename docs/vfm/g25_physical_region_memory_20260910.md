# 物理区域记忆共同求解：本轮实现与验证（2026-09-10）

本轮获得了有效的开发集指标提升。将区域内部的真实米制观测共同用于 PnP，6 米区域按有效观测支持度选择，在两个种子、两条路线均降低平均和中位数平移/旋转误差。当前学习区域选择尚未超过简单物理区域对照，不能把该收益归为学习器收益。

## 评估范围与公平性

同一 StMarysChurch 场景，seq9 的 98 张建图侧查询用于区域效用监督；seq12/seq14 共 224 张开发查询用于验证。两个后端随机种子分别为 260901、260902。各结果单独报告，未将两个种子视为 448 个独立样本。路线间转移不是新场景泛化；这些路线已有多轮开发观察，不是盲测。正式 438 查询主线尚未重跑。

固定候选、RADIO 关联分数、85554 个原型米制坐标和后端参数；每图一个全局组加四个局部组，每组 256 个实际评分假设，总计每图 1280。全部 12 个区域运行均达到相同预算；与原平面组基线的全局初始假设逐图完全一致。比较相同 MoGe v2 精修：区域边界有效像素比例至少 0.75，逐 token 去重及几何接受保护一致。

本轮完成两个半径 × 三种选择策略 × 两个随机种子的 12 次 PnP 和对应 12 次 MoGe 精修，以及两个区域效用模型训练。加入旧固定上下文和旧 ROI 高分辨率读出对照，总共汇总 30 份位姿结果。所有查询参与均值、中位数和召回率；无无效位姿，未剔除大误差尾部。

## 方法上实际改变了什么

1. 在固定米制几何上构建重叠物理区域：以体素内原型均值作区域中心，按真实空间距离确定成员。允许跨平面，每个测量点保留原坐标；区域中心不是被回归的替代测量点。半径 3/6 米分别得到 378/123 个区域。
2. 查询通过现有候选部分激活区域，不要求区域全部可见。支持度对每个查询 token 只取最大关联概率再求和；覆盖策略贪心计算相对已选区域的新 token 证据。四个区域实际进入局部 PnP，最终仍用全部候选逐 token 验证。
3. 学习器使用区域自身的 PnP 初始解误差监督，而不是把同一整图奖励复制给所有单元。3/6 米各用 1250/1211 个区域实例，来自同一批 98 张 seq9 查询。目标为 exp(-平移误差/0.5-旋转误差/5)，失败为零；输入九维支持度、图像覆盖及几何形状统计。
4. 学习选择按预测初始解效用乘以 (0.25+0.75×新增证据比例) 排序。这个目标预测单区域初始化质量，仍不是区域集合的因果边际收益；也没有学习区域边界或成员。

从求解原理看，局部组限制一次假设内部的空间支持，有机会减少来自互不相容位置的错误对应混合；跨表面的真实观测仍能提供姿态约束。全局组保留、假设总预算相同，意味着本轮是在比较分组策略如何利用现有信息。此解释与结果一致，但不是区域方案对所有场景更优的数学证明。

## 对可学习记忆和基础特征的结论

区域化有意义，先前“窗口尺度学习未胜过固定上下文”的负面结果不能否定它。本轮把物理成员真正用于共同几何求解后，固定物理区域即取得了明确改善。

学习器的问题仍未解决。6m 学习选择优于旧基线，却在两个种子的平均/中位位姿误差均落后于 6m 支持度；3m 学习选择更弱。能确认当前学习策略没有带来增量，不能确认方向无效。候选训练区域只来自支持度/覆盖预选；仅一条训练路线；训练区域解用 128 假设而部署用 256；目标偏向独立区域精确初始化，而最终四个区域的目标包含互补和失败恢复；九维统计不描述区域内部视觉配置。上述是明确的建模限制，尚未逐项消融证明谁是主要原因。

RADIO/MoGe 能力没有被证明耗尽：本轮没有改变基础特征，只改变几何组织就提升，说明原后端尚未充分使用已有候选信息。MoGe 使用现有法向/偏移/弱尺度精修；高分辨率读出沿用上一轮独立对照。本轮尚未把区域求解与 ROI 读出组合，也未解决高精度召回瓶颈。

## 建议落实边界与下一步

| 方向 | 当前状态与结论 |
|---|---|
| 物理区域及部分激活 | 本轮已接入真实共同 PnP，有开发集指标收益 |
| 区域自身定位价值监督 | 本轮已训练并转移验证，当前学习器不胜简单区域对照 |
| 多尺度/容量选择、高分辨率及中间层读出 | 上轮已有实验；本轮纳入旧 ROI 对照，参见既有报告，不能说基础特征已耗尽 |
| 任意可学习区域成员/边界 | 尚未实现；目前半径与区域候选固定 |
| 区域整体前端召回与配置匹配 | 尚未实现；本轮在固定候选池上分组，因此不能恢复池外正确对应 |
| 端到端集合边际价值、跨路线训练 | 尚未实现；单区域质量监督只是中间步骤 |
| 只存少量完整地图单元、地图压缩收益 | 未验证；重叠区域保存引用，不能宣称地图只剩少数记忆点 |
| 正式 438 查询及新场景泛化 | 本轮未跑，不更新正式主线数字 |

本轮满足“获得有效指标提升”的阶段目标，并非附件全部研究设想已完成。下一步以 6m 支持度作为固定区域强基线，优先验证正式协议，再组合 ROI/精细读出；学习部分应匹配部署预算、加入多路线监督，比较集合互补目标与当前单区域目标。当前不建议仅扩大选择器或继续无约束扫描半径。
