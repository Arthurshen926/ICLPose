# G25：结构记忆、监督扩充与位姿收益分解

本轮承接完整 MoGe 输入与固定区域均值上下文实验，推进到 token 周围的空间排列、MoGe 相对几何、候选独立的监督扩充、固定预算位姿求解，以及不参与关联模型拟合的路线迁移。没有修改 2DGS、RADIO 权重、地图坐标或主线默认参数。

## 1. 三个实质改进

### 候选独立的完整输入监督

从建图图像的渲染深度为每个 RADIO token 构造目标，要求 16 个支撑像素至少 12 个深度有效，P90−P10 不超过 max(0.25m, 2% depth)。目标位于 token 中心射线上，深度为局部中位数；不向候选平面吸附，不按候选位置挑目标。

随后投影到距离最近的 8 个其他路线建图视角，要求至少 2 个通过深度一致性检查。投影使用原内参及径向畸变；参考深度跨边界时不接受。候选三维坐标在目标文件冻结后才打开。原有已知/歧义标签保持不变，只扩充原 unknown。

seq9 的结果：

- 全图 token 中 104972 个有跨视角一致目标；这不是全部真实 MoGe 区域人口。
- homography 后新增 16551 条正例、11011 条负例；unknown 从 55906 降到 28344。
- 与原标签可直接比较的 11400 行没有冲突。

这些是同一个 2DGS 地图派生的、多视角渲染一致伪监督，不是新的传感器观测或材料点真值。新增正例表示距目标 ≤0.25m 的米制对应，不等于精确的平面实例身份。参考视角排除了整个 seq9，但同一地图的系统误差仍可能共享。

### RADIO 的位置关系读出

对每个 token 的两格邻域划分四个不重叠方向扇区，分别平均并归一化 RADIO-64 特征；排除中心，图像边界按有效像素数归一化。地图原型的扇区读出只由对应建图视角的观测池化获得，query 使用同样的原语。

同时计算无序上下文相似度、同方向相似度，以及固定左右镜像对照。没有最大化旋转/镜像后选最有利答案，也没有新增匹配候选。这是一种保留空间排列的局部外观记忆，仍不是可学习地图分割或任意区域选择器。

当前共有 85554 个匿名原型；四方向 float32 描述子相当于新增 87607296 字节，约 83.55 MiB。不能把这版称为零开销或压缩地图成果。特征文件仅存实验分数，若部署完整地图读出需承担上述描述子容量或另行验证压缩/选择。

### MoGe 的相对三维关系

在独立 query token 的近邻中比较两类几何量：绝对法向内积，以及归一化位移与两端法向的绝对内积。对另一 token 的候选解释按原 RADIO 分数软聚合，每个邻居 token 贡献一次；同样的解释重复出现不增加票数。

这些量对共同旋转、平移、正尺度和法向符号不变。它们不对局部非刚性形变不变，也不能区分所有重复共面结构。MoGe 法向/点图可靠度不足时保留缺失特征，不硬删候选。读取缓存必须明确声明 `uses_pose=False` 和 `uses_ground_truth=False`。

## 2. 固定候选关联实验

98 张 seq9，地图原型排除整个 seq9。原五参数 logistic、各固定消融及联合读出保持 L2=0.001，采用按图像二折交叉拟合；每条观测的部署分数由未拟合该图标签的模型给出。以下为与上一轮一致的 49 图评价子集：

| 原五参数 | 0.947470 | 0.087897 | 0.863404 | 0.194734 |
| 无序 token 上下文 | 0.956441 | 0.078219 | 0.890232 | 0.168945 |

方向排列胜过同容量镜像对照，MoGe 关系也提供独立增量。这支持“已有基础特征中，先前读出丢失了有用信息”，不支持“全部能力已耗尽”。扩充监督改变了训练人口，明显改善新人口标定，但也可能损害旧人口标定；不能只保留更好的一侧。

该实验仍是同一路线的图像交叉拟合；相邻图像不独立，新增标签也是伪监督。多项固定消融属于探索性结果，不能用某一个最好的 AUC 宣称最终精度突破。

## 3. 固定预算位姿验证

全候选保留。每图使用全体候选及按独立 token 支撑选出的四个平面组；每组最多 2048 次抽样，固定评分 256 个有限 AP3P 假设。引导采样保留 50% 均匀探索，精修和评分按独立 query token 计数。两种 seed 的预算逐组均达到，seq9 每臂 125440 个、224 张迁移每臂 286720 个假设。

这是相同“可评分假设数”，不是不同位姿数或相同墙钟预算。不同臂并发运行，日志中的耗时不能充当无竞争在线延迟。

## 5. 精确观测的诊断与否决结果

用标签选择固定候选后运行相同坐标求姿，仅作不可部署诊断：旧正例 11/65/95/98/98，扩充正例 25/90/98/98/98；按 GT 重投影 ≤1px 选择可达 92/98/98/98/98，≤2px 为 79/98/98/98/98。1px 诊断中位平移 0.03781m。

它说明当前候选几何存在能拟合正确位姿的子集，不能证明外观可识别这些子集，也不能当作可实现的精度上限。尤其是米制 0.25m 正例定义仍太粗，不能与精确观测质量混同。

因此新增一个固定 1.5px Gaussian 精度效用目标：已知/扩充米制正例的效用为 exp(−0.5·(重投影误差/1.5px)²)，负例为零，未知仍忽略。仅 seq9 标签用于拟合，不扫描尺度。该输出是精度效用，不称为匹配概率。

实际求姿没有支持升级：质量＋结构在 seq9 两种子分别 25/78/95/98/98、20/79/94/98/98；迁移为 11/68/122/156/171。质量原读出迁移为 15/71/122/155/169。没有形成稳定严格精度收益。

另外对同一个固定候选池做独立 token 的 1.5px 软重投影支持重排，包含无权重控制、原/扩充概率及质量权重。联合结构迁移池原为 16/71/122/155/172；无权重软评分变为 16/75/124/155/170，质量＋结构加权为 16/73/121/152/169。严格门限的局部改善伴随粗失败增加，不能统一替换默认评分。该重排是在开发候选池诊断后的探索性跟进，不是独立预注册确认。

## 6. 方法上的明确取舍

保留完整输入、独立监督有效性、候选独立渲染监督，以及 RADIO 排列/MoGe 相对关系读出。这些落实了定位任务所需的信息组织，有可复核的关联质量证据。

不把当前质量头、软评分或新增监督直接推广为主线提升；不继续扫描这一批图上的阈值。下一阶段需要让训练目标反映一组观测的精度和共享偏差，同时保留对错误身份的判别。可学习记忆单元应在这些证据上按定位价值与成本选择，而不是先将四方向固定窗口改名为自适应记忆。

当前统一地图单元/仿生记忆贡献仍未完成；这里完成的是具有实证价值的结构读出和监督接口。正式正确性基线 96/330/398/409/412 不被本轮条件实验替换。

## 7. 第二种子确认与最终结论

224 张迁移路线，seed 260902：

| 采样分数 | 实际选中五门限 | 固定组胜出候选池 oracle |
|---|---|---|
| RADIO 余弦 | 17/61/119/149/166 | 18/76/127/153/169 |
| 原关联读出 | 16/64/118/149/164 | 19/74/123/151/166 |
| 联合结构 | 13/66/121/151/164 | 15/75/127/152/165 |

相对原关联读出，两种子在 0.25m 门限均净增 2，但分别有 13 改善/11 退步、10 改善/8 退步；McNemar p=0.839/0.815，不支持统计显著提升。0.1m 为 +1/−3；2m 为 +4/0。总体平移中位数分别 0.425232→0.416733m、0.472796→0.437667m，但分路线并非一致：第二种子 seq14 中位数 0.476408→0.509948m。

因此权威结论为：**结构读出提供明确的关联质量提升，并有条件位姿收益；尚无稳定主线精定位突破。** 不能把第一种子的粗门限 +4 当成已确认升级。新增质量头与软重排本轮均不升级。

本轮覆盖 322 张独立图像、同一场景的三条开发路线；重复 seed 和不同模型不增加独立样本量。主线双分支 MoGe 精修后的正式基线没有重跑或更新。
