# 对“学习地图单元没有稳定增益”的范围复核

本记录补充上一轮报告，缩小其结论适用范围。现有负面结果针对“固定候选上的原型上下文尺度选择与增强描述子容量分配”，不能否定区域级关键记忆定位。上一轮将其概括为“可学习地图单元已完整落实”不够准确：有限选择器已落实，区域整体召回、配置匹配及相对位姿读出尚未落实。

## 已接入和未接入的机制

- 原有 0.5m chart 身份格及匿名外观模式继续作为锚点。85554 个原型对应 27069 个身份格，不能等同于 85554 个独立物理区域。
- 学习动作是选择源图像 token 半径 1/2/4，以及是否保存额外上下文。窗口的形状、方向分区、几何支撑关联规则是预定义的。
- 四方向描述子进入关联分数，进而影响现有 PnP 的部分采样。原候选、召回和物理坐标保持不变，因此不能检验记忆组织是否改善召回率或修复候选缺失。
- `reference_bank_rows` 保存了跨表面引用，但当前得分和 PnP 路径不消费它们来形成区域级联合约束。其统计属性参与选择学习，不等于已实现跨表面配置推断。
- 25% 容量指增强上下文存储。未选单元仍保留原始外观、几何和候选，不能用这个实验声称只用四分之一的物理地图就完成了定位。

## 学习目标的限制

当前标签为米制有效性 × 亚像素精度效用 × 关联置信度 × (0.5 + 0.5 × 整图固定 PnP 效用)。同一图、同一尺度的所有原型共享最后一个因子；它没有测量加入或移除某个单元的定位贡献。三种整图尺度的平均位姿效用分别约为 0.4277、0.4190、0.4198。

这允许模型学习“哪些原型通常容易匹配得准”，但不能充分区分冗余的可靠墙面和互补的关键墙角。全局 top-K 选择没有显式约束区域覆盖、冗余、共同可见性或集合的几何条件。尺度通过硬 argmax 选择，尚未验证小预测差值是否足够可靠。

学习选择更集中是可确认的现象；平面覆盖只是代理指标，尚不能据此确认它导致了某一张图的失败。两种 25% 选择的 Jaccard 重叠为 0.1717，说明它们确实选了明显不同的内容。

seq9 中参与选择器监督的可靠、homography 后对应只触及 17463 个原型，占全部的 20.41%；被触及原型的可用对应行中位数为 2。这不是说其余原型没有任何建图监督，而是说当前单元效用学习缺少它们在本轮留出路线中的直接表现证据。131061 条训练记录不能当作同样数量的独立区域或独立视角。

27069 个多模式身份格中，18131 个在不同外观模式上选择了不同尺度，占 66.98%。多视角用不同上下文可能合理，但它说明当前动作主要发生在外观模式层面，尚未学出统一的物理区域边界。

最优与次优尺度预测值的差中位数为 0.00615。它不是校准后的置信区间，不能单凭其数值断言选择不可靠；当前缺少对尺度决策稳定性的检验。

## 下一轮应当检验的对象

保留固定米制几何，先实现固定区域整体召回与匹配控制，使区域身份与内部精确观测分开。再在相同容量与计算上限下，学习选择有稳定物理锚定的表面片段集合，而不只是外观模式的窗口半径。

监督应在多个留出建图路线评价区域配置对固定后端的边际帮助；比较集合覆盖、冗余和可辨识性，不能将整图得分平均分配给所有区域。查询允许部分可见，几何观测仍逐 token 去重。用固定区域、仅学习集合成员、仅学习上下文、二者共同学习的对照分离贡献。

这需要重新定义并检验区域级机制。继续对当前回归器增加容量或扫描三个半径，不能回答用户提出的完整研究问题。当前证据既不能否定关键记忆方向，也不能保证完善后必然提升。
