## 实验究竟验证什么

本轮是**可迁移核心子系统的统一配对实验**，不是把 StMarys 的全部 v414 场景专用补救/验证/精修级联直接搬到五场景，也不是五场景 SOTA 对比。原有 StMarys 90% 级 25 cm 开发结果不能填入本表。

共享的核心：冻结 RADIO 与 StMarys 官方训练路线学习的 64 维投影；训练图像向已有 2DGS 有限表面赋予粗细外观；匿名空间记忆检索；区域互近邻匹配；唯一 query token 的多假设 PnP；受限连续外观精修。所有场景使用同一超参数，当前轮不按测试指标调参。

尚未移植到本实验的模块：query MoGe 有效域/几何筛选、训练的部分重叠/身份匹配器、多轮新增证据补救、v404 等学习验证器、完整 v357–v414 级联和可学习地图成员选择。因此消融能够说明本轮受控管线内的机制效果，不能单独完成历史整套优势的归因。

## 固定消融与理论边界

- `pooled`：四个区域产生的相同匹配库存合并，统一 PnP，最多评分 1000 个位姿模型。
- `pooled_multistart`：相同合并匹配库存也进行四次独立 250 模型求解，使用与各区域相同的随机种子，再按相同全局支持选择。该控制使全局池也获得四次 LM 机会，用于区分区域组织与多次尝试；逐查询断言重算的匹配库存 SHA256 与原实验完全一致。
- `regional`：每区域独立评分最多 250 个模型，保留各区域最优位姿，再在同一合并库存上按唯一 token 支持选择。检索、匹配、亚 token 坐标与 pooled 相同；不同点是如何组织位姿提议。
- `regional_fine`：在 regional 上固定一组支持点，以高分辨率特征场连续优化位姿。每步限制平移 0.5 m、旋转 3°、各支持点像面位移 4 px。
- `regional_agreement`：相同局部优化提议只有在相同支持上的粗、细尺度平均外观分数都提高时才接受；至少 6 个唯一 token。

区域条件化把混合证据中的互相矛盾假设暂时分开，避免少量正确局部证据在全局采样中被稀释。它不保证正确区域一定被检索，也不保证区域内无遮挡。合并评分使用相同观测库存，避免靠候选重复增加票数。

粗细一致性是保守选择规则，**不是独立证据似然相乘**：两层来自同一编码器，且本轮评分支持与优化支持重用，不能声称独立确认或统计独立。信任域只是约束优化步长，不是物理测量噪声模型，也不保证位姿误差下降。

相同预算指相同上限；若某区域不足 6 个有效 token，实际评分模型数可能减少，逐查询审计保留实际值。实验没有 query MoGe 筛选，因此只能隔离以上两个子机制。

## 几何实现检查

初版未经近裁剪的 GreatCourt 首张映射被同一浮片占满：2304 个 token 只命中一个 primitive，交点中位深度约 0.131 m。该版本仅作为失败诊断保留在 `geometry/`，不进入定位地图。

正式版本统一采用 1 m 近裁剪、源 opacity ≥ 0.05、主贡献权重 ≥ 0.05、入射余弦 ≥ 0.2、有限椭圆盘半径 ≤ 3 sigma；在精确 token 中心与主贡献盘平面相交。1 m 是本轮户外场景工程近裁剪，不是所有场景成立的物理定律。它可能删除真实近处表面，不能宣称替代了多视图几何可信性验证。

反投影再重投影检查只是坐标/像素接口自洽检查，不能证明重建深度正确。实际跨视图几何误差、表面完整性和遮挡仍可能成为性能瓶颈。

## 共享全局读出的补充诊断（后验设计）

## 同查询旧主线对照与结论边界

对同一批350张 seq13 官方测试查询，重新使用官方位姿评估旧 v414：平移均值/中位0.2043/0.1061 m，旋转均值/中位0.8362/0.3679°，R10=47.14%、R25=90.57%、R50=96.57%。旧主线成绩在这些相同查询上仍成立；本轮可移植版明显较低。**这既排除了“只因改了测试划分才掉分”的解释，也说明本轮尚未完成原完整主线的跨场景等价迁移。** 旧主线与本轮地图、精修和补救模块同时不同，该对照不允许把落差归因给某一个模块。

## 仍需解决的问题与下一步

1. **先做移植等价验收。** 在共同 seq13 查询上逐阶段复现原完整主线，再把可见性/部分重叠证据、表面可信性和完整补救链变成场景无关接口。本轮五场景核心实验已经完成，原完整主线五场景端到端优势仍未证实。
2. **地图检索单元与位姿求解支持域需要分开。** 当前半径6m的固定区域对 GreatCourt 明显不适用。可检验的下一步是按视角覆盖、几何分布与位姿可观测性扩展多个区域的联合支持，在固定总预算下保留全局探索；不能凭这些实验宣称可学习地图成员没有价值。
3. **绝对精度和长尾仍不足。** 补全全局读出后 GreatCourt 平移中位约1.1m，KingsCollege约0.33m，OldHospital约0.54–0.58m。单靠0.5m信任域局部精修无法处理很多远距离错误初始化。
4. **尚缺深度/可见性 oracle 分解和外部基线。** 本轮自洽投影检查不等于准确重建，也没有隔离重建质量、检索覆盖、候选生成和选择上界，不能武断地将大场景失败归因于某一个环节。没有同地图预算外部定位基线、独立新场景确认与完整成本统计，仍不足以支持顶刊级领先性或新颖性宣称。
5. **真正得到支持的是有限的机制结论。** 共享跨区域几何读出很重要，连续特征对齐有跨场景增益；固定半径区域单独解位姿不构成稳定优势，LoD、匿名地图和生物启发解释本身也未通过独立消融证明因果收益。

验证：基础求解/局部优化28项测试通过，新增共享全局读出2项测试通过；600张建图视图坐标回放通过；2518份特征模型/维度/有限值契约通过；原四端点在15张跨场景查询上逐元素精确重放；120张训练抽样与官方测试清单共16份文件重建完全一致。等多起点与共享读出每个查询都验证了相同匹配库存哈希。固定缓存重放不等于从2DGS训练开始跨硬件逐位一致的复现。


复现补充读出：在原 `infer → control → evaluate` 完成后，以相同启动器依次运行 `--stage readout`、`--stage evaluate-readout`、`--stage summarize`。所有诊断端点在另15张跨场景查询上再次逐元素精确重放（60个位姿数组全部相同）。输入缓存、代码、统计表、环境与报告的哈希见最终归档清单。

独立 gate 消融的具体结果：seed260901 五场景三档召回均与无 gate 的 raw fine 相同；seed260902 仅 KingsCollege 的25 cm召回降低0.292 pp，其余相同。因此本轮没有证据将跨场景增益归功于粗细 gate 本身。
