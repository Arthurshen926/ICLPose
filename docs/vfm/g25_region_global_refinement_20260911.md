# 区域初始化后的全图精修与 ROI 组合（2026-09-11）

本轮获得了相对上一轮强区域基线的新增指标改善。建议保留“6m 支持度区域初始化 → 全图一致观测重投影 LM → 相同 MoGe v2 精修”作为开发操作点。高分辨率 ROI 组合结果混合，不纳入当前方案。正式 438 查询主线尚未重跑。

## 改进机制

上一轮每个区域在自身观测上生成并精修 PnP 假设，最终用全图候选评分选解。本轮在选解后，依据该位姿从全图对应中为每个查询 token 选择重投影最一致的有效观测，以现有 4px 门限保留内点，最多进行三次 LM。每次仅在相同全图独立 token 几何评分严格改善时接受，然后接已有 MoGe 精修。

这里“全图”指当前查询的全部固定候选，不是读取整个地图的新候选。物理坐标、候选和 RADIO 分数保持不变。LM 前把 token/world/pixel 完全重复的备选规范化去重；正深度和每 token 一票沿用既有评分器。推断函数只读取内参，不读取位姿标签，输出封存后另行评估。

新增精修复用上一轮冻结 PnP 初值，未增加 RANSAC 假设，但增加了每图最多三次 LM，不能称为完全相同计算成本。区域初始化提高可靠解的产生概率，全图一致观测精修随后利用区域外的约束；该解释由对照支持，并非对任意误匹配都保证真实位姿改善——接受保护只保证所用几何评分不降。

## ROI 与正式主线的结论

ROI 分数单独接区域求解，两种子的中位平移/旋转均不如上一轮区域方案。ROI 分数加像素读出 S0 部分指标改善，S1 平均平移/旋转和两种中位误差均退步。当前组合不能证明高分辨率读出有稳定增量，也不能证明更高分辨率信息无用；尚未组合 ROI 与本轮新增全图 LM，不将单独结果直接相加。

已检查正式冻结主线入口 `replay_goal_maplet_corrected_baseline.py`：其输入是历史双坐标分支，经过 view geometry、MoGe、uncertainty 以及后续 sparse/dense consensus，和这里的原型候选单分支不同。当前新增模块尚未接入该协议，本轮不声称正式 438 查询得到上述增益。直接替换输入并对比会混入候选与后端差异。
