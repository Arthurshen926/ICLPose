# 实际物理边界、成员与集合价值学习：实现及结论（2026-09-11）

本轮把学习结果真正用于物理区域边界及 PnP 成员，并验证了逐区域独立效用、集合候选池代理价值、考虑实际选择器的集合价值三种目标。完成 224 查询双种子对照，以及两种集合目标各自的完整 438 查询后端重放。考虑选择器的方案修复了一例大失败，降低了平均误差；尚未证明稳定优于固定区域或随机边界分配，不自动替换默认操作点。

## 1. 这次学习的对象

固定同一批 123 个物理中心，对每个中心单独学习半径 r_c∈{3,6,9}m。区域成员为 M_c(r_c)={j: ||X_j−中心_c||≤r_c}，每个成员保留原米制坐标。变化实际进入局部 PnP 分组；全图候选、基础描述子、后续独立 token 验证保持不变。

这是受限边界学习和由边界诱导的成员学习：中心、区域数量和球形边界族固定，尚未实现任意形状、每点独立成员 mask 或自由区域拓扑。它不同于之前仅改变图像上下文窗口，因为三维几何成员现在确实随学习结果变化。

硬约束为所有区域的成员引用数之和不超过固定 6m 基线的 391921。所有地图仍保留 123 个区域；基础地图和外观库没有被压缩，全球候选仍用于全局假设及最后评分，不能宣称只存少数区域就完成定位。

## 2. 三种训练目标及其边界

使用相同的 98 张 seq9 建图侧查询、1211 个已采样的图像—中心组合，补求 3m/9m 的区域初始化及全图精修，复用同配置 6m 缓存。初始解配置为 256 个评分假设上限，冻结候选解后才读取建图位姿构造效用 u=exp(−平移误差/0.5−旋转误差/5)，失败效用为零。

独立效用最大化各中心在已评估建图查询上的平均效用之和。集合池代理目标为 F(S)=mean_i max_{(c,r)∈S∩O_i} u_i(c,r)，O_i 是已评估的候选区域集合：一个查询已有高质量区域时，再添加冗余好区域的边际价值降低。这个目标只是一种候选池上界代理，训练时的 max 使用建图真值效用，不代表部署能选择该解。

为避免只优化“池中存在好解”，增加考虑选择器的目标：在冻结训练区域中按去重观测支持度选四个区域，再与固定全局初值一起按原几何分数选择位姿，用实际选中候选的精修后效用评价集合。选择过程不看效用标签；新增测试明确排除了按真值效用挑最好候选的实现。

边界通过受容量约束的单项改变和一扩一缩交换优化，不需要可微 RANSAC。仅接受训练目标严格提高的更新；这是局部搜索，不保证全局最优。未评估项不作为负标签，只是不提供代理目标中的效用证据；未被训练覆盖的中心保持 6m，这仍会带来覆盖偏差。

训练只覆盖约 49.6% 的固定中心。考虑选择器的目标仍使用已采样区域池，而不是全部可能激活区域；训练 PnP 随机种子按中心身份，部署按激活组顺序；训练效用未包括 MoGe。它更接近 224 查询路径的四区域选择器，但并非完整 438 主线所有分组及后端的精确训练目标。

### 平均误差收益的来源

对 seq13__frame00225.png.npz，固定区域结果为 58.923m / 176.193°，考虑选择器的学习边界改善到 0.303m / 1.584°。它几乎解释了全部平均误差净收益，其他查询的整体变化接近持平。该案例是在结果封存后定位的，没有用它的查询真值设计边界或决定逐图使用哪个方案。

这是一例可复核的大失败修复，不是查询总体都变得更精确。全量中位平移只改善约 1.55mm，中位旋转略退步。配对路线块 bootstrap（3000 次，块长 5/10/20，交错 shard 重新按帧名排序）也不支持普适突破：块长 10 下中位平移差值区间为 [-4.81,1.72]mm。两个正式路线都是反复使用的开发数据，没有新场景盲测证据。

## 5. 当前明确结论

1. 可学习边界与成员已接入实际几何求解。本轮是每个物理中心单独学习边界，并改变真实测量成员，不能再用“仅上下文窗口变化”描述这一实现。
2. 集合价值已做两级实验：冗余感知的候选池代理，以及考虑冻结支持度/几何选择器的目标。后者在完整主线修复了一个大失败，说明实际选择过程值得纳入目标。
3. 学习并未稳定胜过固定区域或打乱控制。224 查询上更贴近选择器的目标没有稳定增益，完整主线收益又集中在单例，证据不足以支持默认替换。
4. 任意形状边界、独立点级 mask、自由中心/区域数量、全候选与完整 MoGe 的集合目标、多路线/新场景监督仍未完成。本轮验证的是受限形式，不宣称附件全部设想已解决。

优先下一步是降低训练—部署差异：用完整可激活区域池及多采样种子估计集合价值，再加入完整后端和多路线监督。仅增加边界自由度可能增加过拟合，当前证据不支持直接跳到无限制成员学习。
