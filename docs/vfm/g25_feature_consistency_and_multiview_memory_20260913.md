# 连续特征一致性与多视图匿名记忆：v344–v348

本轮实现并完成10组配置，每组438张查询。没有达到0.25m/2°召回90%，也没有形成0.5m/5°的大幅、稳定突破。新增多视图地图使同求解器下50cm召回略升，但伴随1m召回下降，应保留为实验分支，不替换现有最佳配置。

## 评估协议

数据仍是StMarysChurch的seq10、seq13两条反复使用的开发路线，五份文件只是计算分片，不是五个独立场景。所有表项使用全部438张查询的最终输出，均无无效位姿。门限同时约束平移和旋转。结果冻结后另行打开真值评估；推理与地图烘焙不读取query真值。开发方向受既有结果影响，不能称为未触碰测试集。未使用时序输入。

直接优化的共同初始化是v327，但本轮增益必须与上一轮v340比较，不能把相对v327的累积收益算成本轮收益。另一个v338配置的50cm召回为95.6621%，高于本轮所有配置；不同配置最佳值不能拼成一个系统。

## 落实内容与结论

1. **多分辨率共同优化**：在相同三维锚点、相同token支持与同一位姿变量上，平均粗、细分辨率的归一化特征残差；鲁棒与普通平方损失均完成全量评估。粗分辨率单独优化作为对照。两级共用RADIO主干，不能视为独立观测。共同优化没有胜过v340的25cm召回；鲁棒版本10cm/1°达到45.8904%，但不能因此宣称用户优先的25cm和50cm同时改善。
2. **描述子公共偏差**：分别固定初始化处的加权平均残差，及在每个位姿处重新计算该均值。后者对均值依赖位姿的项求导，并通过非均匀权重、普通和鲁棒损失的数值梯度检查。固定偏差使平移中位数降至0.106448m，但25cm召回降至89.0411%；动态消偏差降至88.5845%。这表明公共残差可能同时包含位置线索；不能无条件当成应剔除的噪声，也不能由此否定所有外观适应模型。
3. **跨分辨率候选验证**：对v338、v340两个固定端点，以完全相同锚点和分母计算两级残差。双级都改善才接受，或平均残差改善才接受；无证据、非有限、相同分数保留基线。严格规则损失25cm召回，平均规则仅追平v340召回，未获得更优均值或平移中位数。相关特征的一致性不等于物理身份的可靠验证。
4. **多视图固定锚点地图**：对91976个固定世界点，从其原建图相机附近8个相机查找额外观测；按固定相机索引顺序最多接收4个可见观测，与原描述子作归一化均值。投影使用相机径向畸变模型，在同一世界点读取特征，不混合邻近不同三维点。深度检查要求正深度、图像内、有限深度及与干净2DGS dominant depth差不超过max(0.1m,1%深度)。98.9845%锚点获得额外观测，平均4.7431次。地图仅保存匿名描述子，来源相机与文件哈希留在离线审计中；query路线不参加地图构建。原世界坐标、可用标记及全部438张查询选中的token/锚点与v340一致。

多视图鲁棒版相对v340：平移均值下降0.000690m，中位数上升0.000338m，25cm召回不变，50cm提高0.2283个百分点，1m下降0.2283个百分点。按路线时间顺序做3000次配对块bootstrap，块长10时25cm差值95%区间[-1.8265,1.8265]个百分点，50cm[0,0.6849]，1m[-0.6849,0]；块长5和20结论相近。区间未校正反复配置选择，不支持稳健提升的统计主张。

## 理论边界与仍未解决的问题

连续优化估计的是相机位姿T：在固定支持集上最小化投影采样特征与地图描述子的鲁棒距离，并限制相对初值平移、旋转和像素运动。此处支持固定避免优化过程中通过丢掉困难观测降低损失；几何约束限制局部优化的有效范围。它并不证明候选所在的物理区域正确，也无法从局部0.5m信赖域恢复80m级错误。

多视图均值可在观测同一表面且视角变化较小时降低单视图偏差，但可见性不意味着描述子视角不变。有限分辨率的上下文混合、重复结构、遮挡边界和地图深度误差，都会使均值模糊判别信息。最近相机、固定相机索引截断以及近邻像素深度是本次明确的工程近似，不是最优视角选择。尚未验证按观察方向保留多模态描述子、学习聚合或不同相机排序的稳定性。

本轮完成的是高分辨率、描述子偏差、多分辨率验证及多视图匿名记忆的具体控制实验，**不代表附件全部建议已落实或理论已完备**。自由区域边界、成员与集合价值的可靠学习收益，物理身份消歧，新场景及真实困难条件、强外部基线和完整RGB到位姿成本仍需继续。下一轮优先应针对错误位置生成可区分的新观测/候选，或保留方向条件下的多视图描述子；不能继续把平均特征分数下降当作成功定位的证据。
