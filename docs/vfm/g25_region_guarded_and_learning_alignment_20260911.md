# 区域与 guarded LM 组合、区域监督目标对齐（2026-09-11）

本轮在完整 438 查询冻结输入重放中，得到相对既有 guarded LM 强对照的新增召回收益。区域＋guarded LM 的五档召回率均提高，共同有效查询上的平均误差下降；全量中位平移和旋转误差略退步，不能称为全面支配。另完成区域学习监督对齐：加入全图精修后的区域效用标签改善了旧学习器的平均误差，但仍未稳定超过简单支持度选择。

## 1. 完整主线的四组对照

四个操作点构成同输入的组合对照：正确性修复基线、guarded LM、物理区域替换、物理区域＋guarded LM。区域因素只替换 primary 分支的平面种子组，其他种子组保持不变；guarded LM 因素使用既有两个分支的 LM 接受保护。最后完整重跑 view geometry、MoGe、uncertainty、sparse geometry、sparse-first render、双分支 dense rendering 和原共识。

本轮新跑五个 split 的组合方案，引用已经封存的其他三组作为对照。非平面 PnP 候选逐 split 与 guarded LM 对照完全一致。候选人口、坐标、权重、内参不变；区域组调用数与被替换的平面组相同。OpenCV RANSAC 自适应停止，所以不声称实际评分假设数或耗时完全相同。

## 2. 路线差异与不确定性

438 查询仍然是两条已反复使用的开发路线，不是新场景盲测。相对 guarded LM，seq10 的严格召回从 25.00% 降到 23.86%，seq13 从 22.00% 升到 23.14%；两条路线中位平移均略退步。总体收益不能掩盖 seq10 的严格精度回退。

按帧名重新组合交错 shard，再做路线内配对循环块 bootstrap，3000 次、块长 5/10/20。块长 10 下，相对 guarded LM 的严格召回增量 95% 区间为 [-0.92,2.28] 个百分点，0.25m/2° 为 [0.00,3.42]，中位平移差值为 [-2.50,7.42]mm。因此这是实测小幅增益，统计证据仍有限，不能包装为稳定突破。

## 3. 学习区域监督：两项明确对齐

旧学习器对每个区域独立求 PnP，用其误差构造 exp(-平移误差/0.5-旋转误差/5) 标签。问题之一是训练配置为 128 个评分假设、部署为 256；另一个是部署加入全图精修后，旧标签仍只描述局部初始解。

本轮固定 6m 区域成员、相同 98 张 seq9 训练查询、相同九维特征、模型容量、区域候选集合及标签函数，新增两组：

- budget256：仅把训练假设预算配置改为 256。
- budget256_global：相同预算，再对每个区域初始解执行全图独立 token 精修，封存结果后才读取建图位姿构造标签。

三种学习器均用相同 224 查询、两个种子，经过同样的全图精修和 MoGe 后端评估；固定支持度区域选择作为强对照。实际验证阶段每组累计评分假设均为 286720、预算未达到组为零，未通过增加验证预算给新模型优势。训练配置对齐不等于整个部署目标已对齐：监督仍未包括 MoGe 和多个区域共同竞争的最终效果。

## 4. 剩余限制及优先方向

这两组监督共覆盖固定物理区域的 49.59%，仍只有一条训练路线。区域选择使用可泛化的统计特征，因此未覆盖区域不等于一定无法泛化，但不能把大量区域训练实例当成充足的跨路线证据。加入全图精修后，标签排序与旧标签的 Spearman 相关由仅预算对齐的 0.929 降到 0.673，说明监督实质改变；这是标签诊断，不是验证精度。

当前模型预测单区域精修后的独立质量，尚未学习“这四个区域作为集合，对最终位姿增加多少信息”。它也没有学习区域边界或成员、区域整体前端召回或完整 MoGe 后端效用。下一步更有价值的是补齐这些目标与多路线监督，而不是继续只扫描假设预算或增加同一回归器容量。

高分辨率读出的上轮结论保持：有小幅混合增益，插值控制解释了部分收益，本轮没有重新宣称基础特征能力耗尽。本轮满足新增指标提升的阶段目标，但附件的全部研究设想尚未完成。
