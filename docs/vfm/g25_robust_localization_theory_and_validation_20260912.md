# 鲁棒定位的方法合同、理论边界与验证协议

本轮依据最新附件15def69f，将主目标固定为全查询0.5m/5°成功率，1m/10°辅助；保留平均/中位平移与旋转误差及其他联合召回。基线冻结为v304精测＋精测风险备选。拒识、超时和无输出均不是定位成功。本文区分数学性质、已测实现性质和待验证研究设计，不声称理论已经完备或达到顶刊领先性能。

## 1. 问题定义与三类误差

输入为单张RGB、相机内参及建图阶段冻结的匿名米制表面记忆；推断不使用query真值、源图身份或时序位姿。地图记忆包含米制锚点和局部外观，不保证任意两处物理地点可由当前单张图像区分。

每个图像token i具有互斥的地图解释集合 H_i。解释包括物理锚点、局部外观和测量不确定性。一个token的多个解释不能作为多个独立观测。应分别描述：

- 身份错误：选择了另一物理表面，属于离散匹配错误；
- 条件测量误差：身份正确时的二维读出、地图锚点及单目几何误差；
- 不可辨识性：多个远离位姿都能解释当前可见图像。

当前校准方差主要覆盖可信身份下的坐标测量误差，不是错误身份概率；MoGe也不能被当作独立真值。当前分阶段PnP与精修是合理估计实现，不强行把所有启发式称作归一化生成似然。

## 2. 候选覆盖与选择的精确分解

对固定候选集合 C(q)及联合门限τ，令 Aτ={存在T∈C(q)满足平移和旋转门限}，Sτ={输出满足门限}。当输出必须属于该集合时，Sτ⊆Aτ，故

P(Sτ)=P(Aτ)P(Sτ|Aτ)。

这是事件恒等式，不需要候选独立。经验评测分别报告候选覆盖、条件选择成功率、选择损失与候选缺失率。每个门限必须对同一完整位姿判断，不能把不同候选的最小平移与最小旋转拼接。若某个GT奖励选取一个位姿，它只是一种诊断策略，不一定达到每个门限各自的集合上限。

若C⊆C'且旧位姿逐元素保留，则Aτ(C)⊆Aτ(C')。因此候选覆盖单调不减；最终选择成功率无单调保证。该性质已有`test_goal_maplet_candidate_pool.py`验证，包括重复候选不变性、无效值处理、联合门限和分解恒等式。

## 3. token证据的可测试性质

现有几何评分的第一项可写为

V(T)=Σ_i 1[min_{h∈H_i} e(T,h)≤ε且深度为正]。

第二项为固定token集合上的截断重投影误差和。以下结论限定于冻结证据和该评分，不推广到整个学习／检索／求解系统：

1. 重复同一解释不改变最小值和token票数；canonical去重也防止抽样质量重复增加。
2. 固定token总体，删除部分解释不可能提高V(T)。若删掉整个token却改变均值分母，则不再有该保证；验证应冻结总体，缺测单独报告。
3. 对世界坐标刚体变换X'=GX，相机世界到相机位姿变换T'=TG⁻¹，则T'X'=TX，投影和评分不变。测试验证当前评分实现；尚未验证完整地图重建、离散检索和随机求解的端到端等变性。

`test_goal_maplet_robustness_contracts.py`已覆盖上述限定性质。区域重叠的全部先验质量不变性、未知监督不被视作负例，需要单独追踪到各自训练器，不能用这三项测试替代。

## 4. 分歧驱动验证：待落实的设计合同

对竞争位姿A、B，在共同固定图像区域上生成预测，仅根据候选、地图和query选择二者预测差异大的区域D(A,B)。必须有D(A,B)=D(B,A)；交换候选只交换结果，不改变证据人口或候选优先级。验证特征应描述局部外观配置、跨表面相对布局、遮挡和深度层次，而不是只有内点数。

尽量从未参与候选生成的空间区域抽取证据。计算留出不等于统计独立，RADIO/MoGe同源误差仍需说明。两者都缺乏可见预测时标记证据不足，不能按一方更少的分母将其判好。输出须支持A、B、都不可信和信息不足；拒识单独报告覆盖率与错误接受率。

本轮先检查候选池上限。两个v304最终端点在1m/10°没有选择空间，因此粗失败研究必须保留早期候选或补充新的对应来源，不能只拟合这两个端点。

## 5. 区域调度学习的正确目标

后续动作目标应运行完整候选保留与最终验证。可使用预先固定主门限的成功恢复收益，扣除破坏已有成功及计算成本；不再把主分支的毫米级收益等同最终系统收益。动作与停止必须共享query和随机控制，多求解种子估计收益方差，训练/验证按独立query及路线划分。

先验证标签是否稳定，再决定是否需要内容关系模型。固定查询上的公共线性特征在动作排序中会相消，不能通过简单增加同一基础位姿统计量解决动作间辨别。动态中心、边界、成员与压缩不是此轮鲁棒性实验的前提，也不能把固定库在线调度写成已学会地图单元生成。

## 6. 投稿主张与验证门槛

可暂时主张匿名米制表面的上下文记忆补充局部对应，以及校准精测和保留互补候选在开发路线上的增量收益。不能主张通用最优地图、可靠识别所有错误身份、领先成功率、跨场景鲁棒性或完整资源优势。

- 冻结独立场景及真实困难条件，不继续以当前两条路线作为确认集。
- 比较强层次化定位、相关表面/区域或Gaussian方法，以及同特征同地图消融。
- 同时提供各方法合理配置和同时间/存储预算比较；记录RGB到pose的p50/p95、峰值显存、完整地图和模型字节。
- 报告全查询成功率、平移/旋转均值与中位数、P95/P99、拒识覆盖—错误接受曲线；重复路线块bootstrap仅作开发诊断，不能修复选择偏差。
- 预先固定严重误定位定义：平移>2m和旋转>10°分别报告，联合1m/10°为辅助定位指标；2m/45°仅作历史粗诊断。

本轮在当前2dgs_surface输出下仅发现StMarysChurch的已建表面地图；其他Cambridge场景的原图目录、训练/测试列表与SfM训练模型可用，已写出confirmation_readiness.json，未解析其测试位姿。其他场景仍需构建当前方法的匿名表面记忆和配套特征，不能将历史其他方法的结果直接作为本方法确认结果，也不能用当前缓存耗时冒充新场景端到端性能。

## 7. 相关工作约束（已核对原始来源）

两阶段全局检索与局部匹配不是新贡献：[HF-Net](https://arxiv.org/abs/1812.03506)。视图合成验证及结构化密集匹配已有先例：[InLoc](https://arxiv.org/abs/1803.10368)。学习压缩场景地图不是空白：[SceneSqueezer](https://openaccess.thecvf.com/content/CVPR2022/html/Yang_SceneSqueezer_Learning_To_Compress_Scene_for_Camera_Relocalization_CVPR_2022_paper.html)。平面中层结构匹配已有[PlanaReLoc](https://arxiv.org/abs/2603.20818)；无需额外参考图像的Gaussian定位已有[GSVisLoc](https://arxiv.org/abs/2508.18242)。

因此拟议贡献应聚焦匿名VFM米制表面记忆、上下文身份匹配，以及分歧驱动的可靠定位；其中后两项必须以新机制和困难条件实验支持，不能仅通过重新命名现有流程成立。

## 8. 本轮追加门控消融的约束

v308对v307的全部冻结候选重新执行无稀疏门控的成对稠密渲染，并用同一完整query-valid法向分母、原20°阈值选择。没有训练阈值，平局保留基础解；无正证据另存标记，未把该标记变成拒识或定位成功。新工具禁止输入带稀疏调度掩码的报告，核对两端位姿哈希、地图、相机和MoGe来源，避免拿未计算哨兵当真实分数。

实际结果为负：1m/10°从精测控制的96.3470%降至95.4338%，恢复率0、破坏率0.9132个百分点；因此删除门控不是当前有效改进。已有可恢复备选的全量稠密分数也低于基础候选，说明该法向评分不足以决定这些候选的位姿准确性。该实验不是RADIO布局或分歧区域验证，不能推广为所有身份验证都无效。

米级门限失败也不自动等于认错建筑或物理表面身份错误。必须结合地图位置、对应身份和可见结构诊断，不能从1m阈值直接赋予“错误物理身份”标签。

## 9. 单帧身份辨别的可辨识性边界（数学说明，非数据集结论）

考虑两个等先验的物理位置假设A、B，允许验证器使用的全部单帧观测为Y，条件分布密度为p_A、p_B。对任意二分类决策，最小可能错误率为

R* = (1/2)∫min(p_A(y),p_B(y))dy = (1−TV(P_A,P_B))/2，

其中TV=(1/2)∫|p_A−p_B|。证明是对每个y选择密度较大的一侧，剩余错误质量逐点为较小密度的一半，再使用min(a,b)=(a+b−|a−b|)/2积分。

因此如果现有观测对两个位置完全同分布，则等先验下错误率下界为1/2。增加同一观测的确定性变换或反复评分不会消除这一边界；新增可见上下文只有在提供不同的条件分布时才有消歧价值。

该说明不证明当前任何具体查询不可定位：我们没有估计它们的条件分布或TV，也没有证明RADIO/MoGe是原图的充分统计量。它只限定论文主张：不能无条件保证单帧唯一定位，应说明观测、地图覆盖及辨别信息的假设。时序或额外传感器须作为不同实验设置，而不是偷偷加入单帧协议。
