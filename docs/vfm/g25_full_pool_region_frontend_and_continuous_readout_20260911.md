# 完整候选池、区域前端、精细读出与点级成员：新一轮结果（2026-09-11）

本轮获得了有价值的开发集指标提升，主要来自**固定区域外观检索生成新对应，再保留原学习评分进行增广**。相同求解策略下，三个种子的平均平移/旋转误差都下降；这不是学习边界获得稳定优势。完整池边界学习、连续精细读出、显式点级成员及组合/保护对照也已运行并形成受限结论。

全部新性能结果针对同一场景 seq12/seq14 的 224 张既有开发查询。三个种子仍是同一批查询，不是 672 张独立图像。新前端尚未接入完整 438 查询历史双分支共识，因此不能把下列收益加到原正式成绩。强增广及其对照没有无效位姿，均值为完整 224 查询均值；只有新前端独立使用时出现无效位姿，其全量均值保留为 ∞。

## 1. 当前最值得保留的操作点：区域前端增广

离线使用原 123 个固定 6m 区域。对每个区域按建图来源形成匿名外观模式，保留最多四个来源模式，共 484 个。描述子来自既有 RADIO 四方向局部上下文；地图与查询使用同一投影和读出合同。查询以四个固定象限的聚合上下文检索四个不同区域，再在对应来源模式内部做局部描述子互选，生成新的图像 token—原三维原型对应。

这一步查询检索不读取旧候选池、查询位姿或查询标签。新对应中约 96.09% 的三元组不在旧 homography 后候选中；这是候选新颖度，不是匹配正确率。所有三维原型坐标保持原样。它是固定聚合描述子与局部排列读出的受限前端，尚不是可学习的完整关系图匹配器；没有新增 MoGe 关系匹配，MoGe 在后端继续使用。

强增广保留旧候选和旧学习分数。由于新上下文相似度未校准，不直接把它冒充原模型概率：新对应按同查询、同平面的既有最低分进入，缺少该平面时用查询最低分，仍通过原 50% 均匀探索参与求解。该分数仅为保守采样优先级，不是经过校准的概率。

所有强对照使用同一共享区域种子协议：全局组 seed，区域组 seed+1；五组各 256 个实际评分假设，后接同一全图唯一 token LM 和 MoGe v2。新增可选协议的固定基线已重跑，没有把旧分组顺序种子的基线当作完全相同控制。

使用 Beta(1+正视图数,1+负视图数) 的证据规则：至少三个已观察视图，且匹配率高于 0.5 的尾部质量低于 0.05 时剔除。该规则不是经过校准的概率保证，相邻视图及同地图伪标签相关；它只提供受限、数据驱动的成员选择对照。

## 5. 共同旧观测接受保护：没有解决全部退步

额外比较“原位姿＋区域增广位姿”，只在原候选独立 token 几何分数严格提高时采用新位姿，平分保留旧解；选解不读 GT。旧观测只是共同评价集合，并非统计独立的留出数据。

这个版本需要两次完整求解，因此另有两次旧方案求解的等调用数对照。保护版本平均平移约 2.916/3.104/3.122m，明显弱于不加保护的区域增广；它拒绝了不少潜在大失败修复。相对两次旧求解，也没有全面优势。现阶段不追加该保护，更不能将“旧观测几何分数不降”当成“真实位姿一定不退步”。

## 6. 本轮结论与仍未完成项

- **保留并继续验证：** 固定区域外观检索＋新对应增广＋原学习评分优先级。三个求解种子均降低平均平移/旋转误差，随机检索未复现均值收益；但严格召回和较小路线仍可能退步。
- **保留为精度研究对照：** 匹配真实精细特征的离散读出。存在中位误差收益，尚未形成统一升级点。
- **本轮不升级：** 全池学习半径、当前点级可靠度 mask、连续二次峰值、区域/精细直接组合、共同旧观测保护。
- **没有全部解决：** 多建图路线监督、新场景盲测、完整 438 新前端接入、自由中心/区域数量、学习的完整配置匹配、全部地图字节与端到端时延比较。四个推进方向均有本轮受限实现/对照，不能据此说附件所有设想都已完成。

下一步应优先把新对应增广接入强完整主线，并在新增独立路线确认收益，特别检查 seq14 类型退步。当前数据更支持投入前端区域辨认与候选生成，而不是继续无约束扫描边界参数。
