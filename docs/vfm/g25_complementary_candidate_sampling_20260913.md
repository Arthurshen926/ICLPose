# v407：固定共有匹配上的互补候选生成实验

本轮按用户要求，不把航空 LoD-Loc 作为当前任务的主对照或设计约束。实验直接针对现有地面视觉定位系统，测试空间分散、相对几何互补和初始位姿一致支撑能否在相同匹配与假设预算下改善定位。

## 结论

**存在小幅尾部改善，但没有稳定的召回突破；几何信息引导尚未胜过相应均匀采样对照。** 两阶段均匀控制的两个种子平移均值由 v405 的 0.24085/0.24422 m 降至 0.23224/0.23004 m（约 3.6%/5.8%），但 50 cm 召回分别下降 0.23 个百分点、持平。空间分散首种子最好，第二种子明显退化。保留 v405 主结果，不按单一种子的最好表现替换默认方法。

## 实现与对照

- 新增 `feature_extract/tools/vfm/complementary_pose_sampling.py`，通过现有 RANSAC 回调生成四个不同 query token 的样本，50% 保持均匀探索。
- 空间分散：随机起点后，从每步最多 16 个候选 token 中选择距离已有集合最远的 token。
- MoGe 信息：使用相对深度归一化的投影 Jacobian，按共同列尺度白化，增量最大化 logdet(0.001 I + ΣJᵀJ)。无效几何贡献为零。
- 位姿信息：先使用最多 125 个假设求初始位姿，只用重投影误差不超过 4 px 的一致地图支撑构造信息量，再使用剩余预算；总计最多 250 个计分假设。
- 两阶段均匀控制：相同两阶段预算、初始选择和局部 LM 次数，第二阶段使用均匀采样，以排除多一次局部优化造成的混淆。

四个冻结区域、MNN prototype 身份、query token 和像素逐项与 v402 相同；每区域最多 250 个计分假设、1250 次尝试。两阶段最多 6 次 LM，单阶段最多 3 次，因此几何信息两阶段必须与两阶段控制比较。相同假设数不意味着相同运行时间。每个策略均运行 seed 260901/260902、全部 438 个 query，以及细坐标精修、冻结 v404 相对验证器、v405 额外支撑确认。

本轮没有扩大地图区域、训练新匹配器或实现可学习 LoD 成员。原始选择器使用共同 MNN 并集评分，与旧 raw top16 选择器不同，因此不能把 raw 阶段差异归因于采样。最终对照使用相同保留区域精修和验证流程。

## 是否真的生成了新机会

将最终成功查询与旧 v402 首种子“强基线 + 全部保留区域精修候选”的逐阈值 oracle 比较：空间分散两个种子都在 50 cm 下新增 0.23% 全体查询的覆盖；首种子在 1 m 下新增 0.46%。所有策略在 10/25 cm 下均未获得超出这个旧池的最终成功。这说明有少量新机会，但不支持广泛改善候选空间。该比较仅针对旧首种子池，不是所有历史候选的联合上界；oracle 只用于事后诊断，不进入推理。

**seq13 frame00142 遮挡塔尖样例在全部八组最终结果中仍为 17.253 m / 116.969°，没有修复。** 本轮冻结的匹配输入构成实验限制；不能据此断言塔尖无法定位，也不能声称几何分散已找到真正共有的塔尖区域。

## 方法层面解释

对于已知正确、局部线性化且噪声模型适当的对应，JᵀWJ 的增加可以改善局部约束。这里的信息矩阵采用归一化代理，没有经过噪声标定；它既不是后验协方差，也不能证明某个匹配身份正确。空间分散甚至可能优先选择远处遮挡物；初始位姿条件化也可能继续强化错误模式。两阶段均匀控制的结果说明，观察到的部分收益可以由重复假设生成和局部优化解释，而不能归功于信息量准则。

因此应先解决“哪些观测与候选地图具有相同物理身份”，再解决“这些已可信观测还缺哪个位姿约束方向”。本轮证据排除了把纯空间跨度或未校准 logdet 直接当共有性/成功概率的做法，尚未否定具有正确身份监督的互补区域展开。

下一步最有价值的实现是：共享物理地图 token 的结构匹配器、可拒配的共有区域选择，以及跨当前候选区域补充可信观测。应使用实际强基线输出构造 mapping 侧风险训练/标定协议，避免继续在开发查询上调整接受阈值。按需展开需要独立实现并比较相同计算预算的固定区域控制；本轮尚未完成这些内容。

## 验证与局限

- 142 项相关测试通过，包含 PSD、MoGe 全局尺度不变性、无效深度零信息、token 不重复和保留探索，以及既有匹配、RANSAC、验证合同测试。
- 八组全部区域的身份/像素一致性与假设/尝试上限审计通过。
- 验证沿用完整候选无关 bank，未误用只覆盖旧触发集合的惰性 bank；使用现有地图、相机与输入身份合同。
- 额外验证 token 与直接拟合对应分离，不表示编码器、全图外观或几何归一化统计完全独立。
- 438 查询来自持续使用的同场景开发路线；两个随机种子仅检查随机稳定性，不是独立场景或统计显著性证明。
- 求解器耗时是并发局部计时，不是端到端 RGB→pose 的公平速度评估。

附件中的真实风险协议、完整结构匹配器、在线身份与几何联合展开、独立场景验证仍未全部完成。本轮有明确实验结论，但不能声称附件已全部落实或方法已达到全面合理性。
