# G25：独立观测采样、真实候选关联与联合坐标实验

日期：2026-09-10。对应外部附件 `376dc43b-a41b-4678-9e99-fb37043caabc`。

## 结论与边界

本轮得到一个完整系统的小幅正面结果、一个固定初值坐标学习的正面但混合结果，以及一个偏向粗定位尾部的采样结果。没有证据宣称稳定泛化突破；不替换默认配置、不恢复有错误的历史实现。

主线仍为：匿名多视角有限表面地图 → RADIO 区域召回 → 表面内多候选与连续坐标 → 鲁棒几何求姿 → MoGe 稀疏/稠密几何共识。没有改为原图检索或 hloc。地图含派生多视角信息及离散空间原型，不是无点、无视角信息地图。MoGe 的辅助尺度与法向不等于真实深度；米制基准来自地图。

以下路径前缀 B 为 `/root/ICLPose/output/g25_pose_transport/planar_map_rendered_ransac_v1/surface_coordinate_upgrade_v1`。所有实验为已有开发数据；438 张、5 个 split 只有 2 条路线，并非独立盲测。冻结输入后端重放不等于 RGB 到建图到定位的完整端到端部署。

## 1. 正确性基线与 LM 更新保护

此前完成正确性修复后的双分支共识基线：96/330/398/409/412。历史 104/336/395/409/413 仅归档，不再当作当前代码成绩。门限依次为 0.1m/1°、0.25m/2°、0.5m/5°、1m/10°、2m/45°。

发现默认 unique-token LM 虽然输入去重，却无条件返回精修提议。增加可选 `unique_token_guarded_lm`：保存原始 RANSAC 位姿，对原始候选行按独立 token、正深度和截断重投影误差评估更新；只有字典序支持/损失改善才接受。它保证该局部评分不退，不保证 GT 位姿误差不退。

完整重跑两条坐标分支、MoGe 优化及稀疏/稠密共识：

| 配置，438 张 | 0.1m | 0.25m | 0.5m | 1m | 2m |
|---|---:|---:|---:|---:|---:|
| 正确性基线 | 96 | 330 | 398 | 409 | 412 |
| LM 更新保护 | 99 | 331 | 398 | 409 | 412 |

严格门限 10 张改善、7 张退步，McNemar p=0.629；0.25m 为 4 改善、3 退步。平移中位数 0.162160→0.161573m，但有限配对平均变化 +1.232mm，10 帧分块区间 [-2.386,+5.608]mm。粗失败集合未变。结论：可复现实验候选，非统计显著增益；默认仍为 `unique_token_lm`。

## 2. 更新粗失败归因

按修复后基线重新分析 26 个粗失败：13 个硬关联/PnP 初始化，7 个候选丢失或下游退化，3 个支持不足，3 个最终选择。旧 25 个的 15/6/3/1 不再用于新基线。

## 3. 同预算、独立 token 的几何/分数引导采样

采样、评分、LM 均使用独立 query token。保留所有解释，50% 均匀探索；引导部分先选择物理平面，再按图像空间分散程度选择 token，可叠加同平面内匹配分数秩；同 token 多模式归一化，避免模式数量变成观测次数。固定每 seed group 256 个有限可评分 AP3P 位姿，最多 2048 次抽样。预算不是不同位姿数或等墙钟时间；OpenCV 仅作为原初始化器上下文对照。

### 实验审计发现并修复的问题

第一版先选 token 再在平面内给候选加权。实际 438 张共有 351340 个 (token, plane) 组，没有一个组有多个候选，分数加权没有作用；几何/分数结果差别来自不同 RNG 调用。撤回第一版“学习分数有效”的解释，保留归档，不删产物。新版改为在平面内给 token 排优先级；增加相同分数时几何/分数采样 RNG 完全一致测试。

新实现标识 `plane_first_spatial_score_token_priority_v2_shared_rng`。完成 seq10+shard0 共 176 张，各臂有效评分数均为 1401856；同样有 3 个组未达到预算，不能说每组都完成。初始化阶段：

| 采样 | 选中命中数（五门限） | 候选池 oracle | 按独立支持取 Top-4 的 oracle |
|---|---|---|---|
| uniform | 31/107/157/166/170 | 35/118/160/168/172 | 35/118/160/168/171 |
| geometry | 29/115/151/168/170 | 33/120/159/168/171 | 33/119/156/168/170 |
| geometry+score | 26/121/150/165/170 | 32/126/157/167/172 | 32/125/155/167/171 |

oracle 只在冻结后用标签评价，不可部署。分数优先提高了 0.25m 候选生成，却没有一致改善其他门限及候选保留。

相同历史 MoGe 权重/关联策略，继续跑完整主坐标分支后端（不是双分支最终共识）：

| 176 张主分支最终结果 | 五门限命中 |
|---|---|
| 正确性 OpenCV 基线 | 36/133/163/169/170 |
| uniform | 35/132/162/168/171 |
| geometry | 32/131/165/170/172 |
| geometry+score | 34/130/165/169/172 |

结论：几何引导有粗门限净增 2 的迹象，但精定位退步，不直接替换初始化器；下一步只适合预先固定预算的补充候选/保留机制试验，不能事后逐图选优。没有做多随机种子或未见路线确认。累计求解秒 uniform/geometry/score 为 212.9/508.7/535.8，包含并发竞争，不能作为在线延迟；至少不能声称免费增益。

## 4. 真实跨平面检索候选与关联学习探针

对 mapping 查询排除整个 held route seq9 的地图贡献，用 fit 视角构造匿名 cell 模式；跨全部平面 Top-10 召回，再调用运行时 MNN 和米制 homography 匹配原语。先冻结候选，后打开 mapping 几何生成监督，不先筛正确平面/cell。

1787 个区域，正确平面身份在 Top-10 中为 1447。homography 前 90100 行，之后 61469 行；后者包含 6833 正例、16691 负例、37945 模糊例，以及 52629 跨平面行。定义为同平面且空间距离≤0.25m 正例，距离>0.5m 负例，其余忽略；相邻 cell 或近平面边界不强判负。

独立 token 统计发现审计脚本最初按 bank 观测行计数，会重复计算不同平面的同一 (source image, query token)。已修正；权威补充人口报告为 v199：过滤后 32563 个独立 token，其中 6830 有正例、19665 只有模糊/无正例、6068 只有负例。分母仅含进入 MNN 候选池的 token，非全部 query token。旧 v188/v194 报告中的该计数字段不再使用，原候选数组未改。

增加固定 5 参数 logistic 关联探针（余弦、召回秩、homography 残差/有效性），按源图像分离 fit/eval，按独立 token 与图像平衡权重，模糊例忽略。49/49 图像，11738/11786 个非模糊过滤后样本。AUC 0.94495→0.94680；相对余弦单特征标定控制，Brier 0.10712→0.08417，BCE 0.35341→0.28529。

结论：检索秩/几何上下文有条件标定价值，排序增益很小，尚无定位收益证据。它不等于完成部署关联头：区域仍由 mapping 观测定义，非独立 MoGe 分割；同路线图像分离不是未见路线；忽略模糊样本后的概率不是整体可靠率，尚未训练 null/候选缺失决策。不要把上述标签称为深度真值。

证据：`B/mapping_crossplane_retrieval_v194.{npz,json}`、对应 `.labels.npz`、`B/mapping_candidate_population_v199.json`、`B/mapping_crossplane_association_probe_v198.json`。

## 5. 每图/每平面共同偏差与联合坐标损失

冻结旧头重放，导出平面、独立 token、左相机 SE(3) 投影 Jacobian 与相机点。旧数值数组保持不变（比较需允许被 mask 的 NaN 相等）。不根据 GT 误差选择模式：固定每个 (图像,token) 的首个模式，统计有符号偏差、秩与弱方向，再将残差线性投影到同一相机增量。

49 张图、690 个平面组：旧 base→局部相关头的共享平移偏差中位数 0.05836→0.06194m；27 图改善、22 图变差。说明平均坐标误差下降不能代替共享位姿一致性。此为固定 Jacobian 的局部诊断，不是实际非线性位姿求解或跨表可直接比较的量。

新增可选联合重投影损失，保留图像/UV 两端监督；投影在同一 anchor 切平面上比较预测与目标 UV 的变化，不强行拟合不可由 UV 消除的法向高度偏差。固定权重 0.5、1200 步，不扫权重。默认权重仍为 0。

mapping heldout 对旧局部相关头：联合重投影中位数 0.75319→0.74911px、P90 1.45151→1.44702px；但单端图像 median/P90 和 UV P90 小幅退步。共享平移偏差中位数 0.06197→0.05871m，但仅 20 图改善、29 图变差。不能只选择有利统计。

固定 seq10 的原候选身份、RADIO 分数、相机内参、初值及 isotropic 后端，只替换坐标头：79536 行的身份/索引完全相同。

| 88 张固定初值坐标对照 | 五门限命中 | 平移中位数 |
|---|---|---|
| 原局部相关头 | 20/71/84/87/88 | 0.140947m |
| 联合坐标头 | 24/72/84/87/88 | 0.146851m |

严格门限 4 改善、0 退步，p=0.125；54 张平移改善，平均变化 -1.855mm，10 帧分块区间 [-4.213,+0.585]mm。结论：值得继续验证，有严格命中改善但中位数退步；不是完整 438 主线增益，不能与 LM 的 +3 相加。未完成与新基线/LM 的组合或跨路线定位验证。

证据：`B/mapping_pose_bias_v190.json`、`B/mapping_joint_coordinate_head_v201.npz`、`B/mapping_joint_coordinate_geometry_v206.json`、`B/mapping_joint_pose_bias_v206.json`、`B/joint_coordinate_v208_corr.npz`、`B/joint_coordinate_v208_paired.json`。旧控制 `B/source_modes_v159_isotropic.npz`，共同初值 `B/learned64d_strict_seq10_h025_sourceisolated_v11_v135_moge.npz`。
