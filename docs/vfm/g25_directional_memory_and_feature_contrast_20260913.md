# 视角条件匿名记忆与跨分辨率差分：v349–v352

本轮完成13个配置，每个配置全部438张查询。最有价值的新配置是多分辨率鲁棒初始化后，进行带运动正则的细分辨率精修（v353 constrained_joint512）：10cm召回46.8037%、25cm召回89.7260%、50cm召回95.4338%。这是本轮小幅正向进展，尚未达到25cm的90%目标。评价优先级是25cm/2°、50cm/5°，同时报告10cm/1°和全体位姿均值、中位数。不能拼接不同配置的最佳门限。

## 实现与受控变量

### 视角条件匿名地图

在上一轮相同91976个世界锚点、相同映射相机与深度可见性检查下，保存最多5个描述子及世界坐标系中的观察方向，不保存相机身份或源图像。离线来源另存哈希审计。新地图的均值描述子、三维坐标和可用集合逐元素复现v347。

初始预测位姿给出相机中心C，对世界锚点X计算单位方向(C-X)/||C-X||。读出采用最大方向内积，或固定15°角带宽的指数权重。权重仅用方向，不用query外观或真值；在本次局部优化期间冻结，避免因目标随优化移动造成未求导的变化。普通与鲁棒损失各验证两种读出。原初始化v327、每query选中token与锚点、512支持上限和几何约束不变。

多方向地图压缩文件80,153,453字节，上一轮均值地图23,800,010字节，约3.37倍。额外方向是匿名几何属性，不是源视图ID，但仍增加存储；不能声称成本相同。

### 跨分辨率差分特征

在相同像素处分别双线性采样并归一化细、粗RADIO特征，再对两者差归一化，构成差分特征场。解析梯度包括两次采样和差分归一化的链式导数。地图端对既有细、粗描述子之差归一化。验证差分普通、差分鲁棒，以及差分与原细特征鲁棒目标等权共同优化三组。

这只是跨分辨率差分，不是严格的傅里叶高通或独立新证据。两级共享主干；差分可能放大噪声，近零差分尤其不稳定。地图描述子为既有float16缓存，不能声称无限精度。没有新增query真值或时序输入。

### 分阶段优化和重复细精修对照

v353以v344多分辨率鲁棒预测为初值，再做细分辨率优化；v354以v340细分辨率鲁棒预测为初值，重复细分辨率优化。两者均测试带运动正则、无正则普通、无正则鲁棒三组，使用相同支持生成规则和预算。第二阶段按新的初值重新筛选原候选对应，而不是沿用第一阶段的固定支持，因此结论针对整个分阶段流程，不能单独归因为优化器逃离局部极小值。每阶段内支持固定。

0.5m、3°、4像素信赖域相对于各阶段初值，不再是相对于v327的总预算；叠加阶段增加计算并可能扩大累计运动。这是新增计算的控制实验，不是同总时延比较。读取器只接受验证哈希、无query真值、无运行时源RGB的匿名特征位姿输出；最初不支持该输出类型的问题在生成结果前已修复。

## 结论与适用边界

**分阶段精修是本轮应保留的方向。** 相对v340，10cm提升2.5114个百分点，25cm和50cm各提升0.2283个百分点，1m保持97.0320%。相对此前10cm最好的v344，多出0.9132个百分点，25cm增加0.6849个百分点。平移均值/中位数为0.697047m/0.107783m，旋转均值/中位数1.820692°/0.348668°。历史v338另一个配置的50cm仍为95.6621%，因此本轮没有更新50cm单项最佳。

以同样第二阶段带正则优化对照，重复细精修只有44.0639%/89.0411%/95.2055%的10cm/25cm/50cm召回。结果支持进一步研究分辨率阶段顺序与初始化，但支持重选和目标改变同时存在，尚不能给出唯一因果归因。分阶段的无正则两组亦未胜过带正则组，说明后续精修保留相对初值的运动惩罚可能有价值。

配对路线块bootstrap使用3000次重采样，块长5/10/20。块长10时，v353对v340的10cm提升95%区间为[0,5.0228]个百分点，25cm[-1.1416,1.5982]，50cm[0,0.6849]；对v344的10cm区间[-1.3699,3.1963]。这些数据来自反复调试的两条路线，未校正多配置探索，不能称为独立显著突破。

**差分特征在本设置下应停止作为独立定位信号。** 单独使用25cm下降到68.9498%–71.2329%，与原细特征等权联合也仅84.9315%。这支持“跨分辨率变化不仅是需去除的共同偏差，差分也未必是稳定位置线索”的解释；解析导数测试通过并不能保证所优化目标具备正确的物理辨识能力。


方向最近的鲁棒版本10cm召回45.6621%，相对v340的44.2922%有所提高，但没有超过上一轮多分辨率鲁棒45.8904%。25cm召回89.2694%亦未胜过历史89.4977%。方向核鲁棒版本降低了平移均值到0.695445m，但不能将均值改善当作成功率突破。

这些结果不支持“保存方向模式就能大幅提升定位”的结论。方向接近仍不能保证遮挡和图像上下文一致；建图相机中心邻近不保证方向覆盖广。方向由初始预测提供，因此错误区域的初始化仍可能选择自洽的错误记忆。当前局部优化也不能从0.5m步长约束中恢复几十米位置混淆。

## 验证与复现

- 21项相关测试通过：新增方向模式置换、填充忽略、全局坐标系变化不变性、无可用模式拒绝，以及差分特征解析梯度与数值梯度对照。
- 所有推理输出冻结后才在独立评估脚本中打开真值。两条路线仍是重复使用的开发数据，不是新场景泛化或独立显著性验证。
- 全部13组共5694个输出重算每阶段运动约束通过；方向和差分实验支持与v340一致，分阶段和重复精修的支持按新初值重新选择。
- v350、v352、v353、v354目录保存每分片命令、最终位姿、固定支持和优化审计、逐查询误差及全部指标。v351目录保存本轮代码快照、来源哈希和配对差异。
- 推理使用缓存特征，不代表RGB到位姿完整时延；没有切换默认配置。
- 附件建议仍未全部完成。物理身份消歧、新候选恢复、可学习区域集合价值以及冻结新场景和强基线验证仍未由本轮解决。
