# 新附件首轮：共同配置匹配、候选保留与成员学习监督准备

本轮按附件55404e60推进P1，冻结原强后端，不再围绕旧精修终点调损失。实现了真正重新生成token—atlas cell对应的固定区域配置匹配，并完成MNN、独立Top-1、共同关系、打乱关系控制；追加绝对未知分数、软锚点容量、原生法向、全部区域候选精修保留及第二随机种子。

**结论：有新的候选级机会，但没有可替换强基线的最终性能提升。** 第一种子产生了此前57种精修配置没有的50cm和1m候选，第二种子未复现这些严格门限收益。直接共同重投影评分引入大量错误替换，所有最终方案均不晋级。强基线维持10cm/25cm/50cm/1m召回47.2603%/89.7260%/95.4338%/97.0320%。

本轮是固定区域匹配原型与监督数据准备，不是已经学会自适应记忆成员。最新附件四组实验的固定地图两组已有原型对照；学习地图两组未完成，独立新场景也未完成。

## 1. 实际改变了什么

固定123个原有区域中心、6m范围、原RADIO-64、米制世界锚点。匿名上下文库全库检索4个不同区域。MoGe可靠token按图像顺序均匀选取最多256个。在每个区域内重新计算外观相似度，保留4个不同texel身份；不是从此前57种最终位姿中重排。

MNN控制保留互选关系；独立控制在同一候选集内独立决策；共同匹配在图像近邻图中传递配置兼容性；打乱控制置换MoGe点和法向与token的关联。区域分别求PnP，跨平面世界点保持自己的坐标，未压成同一个平面或UV。每个区域评分假设上限250，四区域总上限1000；原始像素使用token中心，没有调用原学习子token头，因此本实验前端不等于完整旧主线的复现。

图关系同时使用局部距离比与法向夹角。法向只比较各自坐标域内的夹角，不直接比较相机法向和世界法向。尺度由当前独立外观候选的距离比中位数估计并固定，不读取query姿态。MoGe局部形变仍可能造成错误关系，兼容性被截断并仅作为软信息。

最初相对unknown原型不能区分低相似度的区域外token。后续用冻结投影器建图验证集的正/同平面负描述子余弦均值中点作为绝对unknown分数，同时限制同一精确锚点的总软质量。这是建图统计导出的启发式分数，**不是校准匹配概率或真实可见性模型**。两项在v364共同加入，不能把全部变化分别归因于某一项。

初版PCA法向是工程近似；v367/v369改为与atlas构建哈希完全一致的2010个原生平面法向。预运行v360曾把无法估计的零法向当作有效关系，已修复为未知、不贡献法向惩罚；该预运行不纳入正式对比。正式保留PCA对照为修复后的v362/v364。

## 2. 理论定义及严格边界

每个token的状态是4个互斥atlas身份加一个unknown。外观logit为相似度/温度，减去共同常数仅用于数值稳定。共同匹配迭代为：

p_i <- (1-eta)p_i + eta softmax(a_i - beta * mean_j E_{p_j}[C_ij])，eta=0.5，5次迭代。

C由截断的log距离比差及unsigned法向角差构成。不存在或无效的法向关系不给负证据。软容量投影只减少锚点概率，把剩余质量归还unknown，因此每个token的总质量仍为1，完全相同锚点的软总质量不超过1。**最终argmax并不保证严格一对一；同cell不同匿名模式也不等于同一个精确锚点。** 不将此包装成最优传输解或严格物理排他性。

可检验的性质：组件对两侧独立刚体坐标变化不变，正的全局尺度变化由logscale抵消，解释顺序置换只置换概率列，unknown不产生平均世界坐标，原世界锚点不被优化改变。PnP按唯一token计票，重叠区域的重复解释不会增加同token票数。

不保证的性质：该度数归一化消息迭代没有证明收敛到某个全局最优，没有单调能量下降或校准概率保证；距离和unsigned法向关系不能区分所有全等重复结构与反射歧义；单目几何局部误差不能靠全局尺度归一化消除。这里的测试只验证匹配组件与既有求解合同，不证明整个检索系统的端到端等变性。

## 3. 冻结后端与最终选择

对新区域候选使用已有多分辨率鲁棒精修，再使用lambda=0.02的普通细特征精修。支持来自新生成的对应，阶段内固定，每阶段相对自身初值执行0.5m、3°、4像素约束。

v363/v365先按共同唯一token得分选一个原始候选再精修；v366/v368/v370保留各区域候选分别精修后再比较，避免提前丢掉机会。与强基线竞争时，在同一冻结新对应总体上计算相同token重投影分数，至少24支持且严格改善才替换；否则保留原强位姿。这个控制**不声称评分是独立验证或可信概率**。

它失败不仅可能来自物理身份问题，也涉及测量目标不一致：新对应采用token中心，强基线优化的是连续特征目标。一个更贴合有量化误差中心的位姿可能比真实更准确的位姿得到更高重投影支持。不能将全部替换失败归结为“RADIO缺少身份信息”。

## 5. 新候选机会确实出现，但还不稳定

S0原生共同匹配、保留全部候选：相对历史57配置事后池，50cm覆盖95.8904%→96.1187%，1m覆盖97.0320%→97.4886%。这些是GT诊断，不是可部署成绩。

具体例子seq13/frame00254：强基线46.6112m/179.8578°；S0新分支得到0.498701m/2.22983°。另一个查询frame00147出现0.969272m/2.43917°候选。这说明新对应与区域分支能够跨出旧局部初值，不能再一概说新工作只是旧端点重排。

但S1未复现新增50cm或1m覆盖。frame00254最好平移候选约1.66635m/6.53855°；2m门限另出现frame00142的1.96800m/5.37469°候选。两种子机会不同，不能挑S0或挑每query最佳种子宣传稳定恢复。最终选择会破坏已有正确结果，所以不升级默认方法、不宣称本轮最终成功率提高。

阶段诊断分开保存基础位姿、全部原始候选、全部精修候选和实际最终选择，避免把可恢复机会当成实际收益。完整检索/物理身份/匹配因果归因仍未完成，几何投影相符也不是独立身份GT。

## 6. 成员学习的数据准备：实际完成与未完成

v371/v372复用140张建图查询：训练路线seq1/2/4/6共80张，开发校准路线seq7/8/11共60张。每条路线先排除自身来源的atlas外观成员，再实际重建区域描述，执行完整区域库Top-8检索并冻结结果，最后才打开建图相机与干净2DGS深度生成监督。没有使用seq10/13查询标签训练。

v371显示整图区域“可见”标签过宽：1120个检索query—区域组合中88.39%为可见。它不适合直接当单一地点类别，不能把同一图像里多个可见区域互相当负例。

v372细化为query局部四分块与区域配对，并要求至少6个不同texel提供可见支持，避免匿名模式重复把少量几何证据放大。共4480条局部监督，49.13%可见正例、42.99%完整投影不在该块内的负例、7.88%未知。遮挡、边界不确定或空成员保留未知；未知不自动作负例。这里是共享米制地图和clean-2DGS下的可见性代理监督，不是独立物理身份真值。

已落盘每路线的成员索引、重新编码的描述、来源排除、实际检索分数、局部可见锚点、训练/开发划分和来源哈希。**没有拟合成员权重、没有完成学习成员区域＋MNN/共同匹配两组，也没有学习自由中心/数量。** 目前范围仍6m固定；上下文成员与几何成员独立学习、描述与成员联合构造属于下一阶段。

## 7. 新颖性和投稿边界

几何关系编码本身已有[GeoTransformer](https://arxiv.org/abs/2202.06688)；根据另一侧观测预测重叠与可匹配性已有[PREDATOR](https://arxiv.org/abs/2011.13005)；利用冻结基础特征进行鲁棒密集匹配已有[RoMa](https://arxiv.org/abs/2305.15404)。本原型不是这些模型的复现，也不能把软关系、unknown或多分支单独称为首创。

可研究的贡献仍是：围绕真实混淆地点学习米制表面的记忆成员与描述，并让其关系实际改变对应生成。本轮完成了固定成员共同匹配及监督准备，只提供组件性质和开发实验；尚不足以支持顶刊领先鲁棒性主张。

下一步应优先利用局部、路线排除监督学习匹配重叠和成员/描述，而非继续叠加同源重投影门控；并接入测量目标一致、候选对称的外部检查。必须在相同强匹配器下比较固定与学习地图，同时控制地图字节、唯一几何、实际匹配量与完整运行时间。

P0只冻结了当前强基线和ShopFacade确认协议预留，没有完成新场景定位。其他场景仍缺当前方法的原生表面记忆和匹配特征；这不是“独立确认已启动运行”。新场景强基线、真实困难条件、完整RGB到pose时延与显存、错误接受校准仍待完成。

## 8. 验证和资源

26项相关测试通过，包括新关系组件的刚体/尺度不变性、解释置换、unknown处理、软质量约束及监督去重/遮挡未知；源文件编译和git diff --check通过。

所有最终输出与各自接受规则逐元素核对；每区域不超过256个唯一query token，总评分模型不超过1000。实际有效模型数并不总相同，例如S0原生MNN平均996.58个、joint平均894.41个；因此这里只能声称同上限，不能声称实际假设量或端到端成本完全相同。所有运行使用缓存特征，额外精修候选增加计算。没有跨场景或同完整成本优越性的证据。

v363/v365/v366/v368早期输出metadata中的base_pose_preserved_if_not_selected字段过宽；其语义只适用于selected输出，refined输出本就可无效且不回退。写出器已修正，冻结位姿和指标没有修改，S1输出使用修正说明。该元数据问题不影响任何计算。
