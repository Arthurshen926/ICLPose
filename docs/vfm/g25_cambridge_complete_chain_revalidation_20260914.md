# Cambridge 原完整方法重新验证（v417，进行中）

本轮纠正 v415 将“凝练核心机制”误作“简化实验方法”的错误。v415 五场景结果只能描述该简化实现，不能作为旧 v414 完整方法的多场景性能，也不能据此断言旧方法的泛化能力。

## 固定的完整推理链

保留原始 RADIO 点坐标与表面坐标两个初始匹配头、wide8 与 risk9 两路区域增强、全局 token 候选、两路精细可靠性读出、MoGe 和不确定性选择、几何/渲染一致性、多候选保留与精修；随后执行 v313/v319 投影结构及深度可见性、v326/v327 救援、v344 鲁棒多尺度精修、v357 正则化精修、v402 两个种子的 LoD MNN 候选、v404 相对验证、v405 未参与拟合的证据确认、v409 学习式局部精度选择、v411 联合候选、v412 多模态保留、v413 双支持验证以及 v414 多尺度局部一致性。

只跳过不属于历史最终输出祖先的独立对照臂，绝不删除产生最终输出的分支。新脚本适配路径、查询分片、设备及延迟评估接口，原数值算子和参数不变。v409 同时依赖两个种子的候选池，必须一起计算。

## 等价性与新实验是两件事

- `replay_complete_frontend.py` 从冻结初始匹配、地图、特征、MoGe 和拟合权重重算全部前端位姿算子。
- `replay_complete_backend.py` 将新前端输出接到 v414，后续位姿目录强制使用新产物，禁止回落到历史预测。
- 原查询重放逐个比较 NPZ 非元数据字段的名称、形状和值，不能只比较汇总召回率。
- 初始点/表面匹配另外重建验证：身份、坐标和相机一致，少数 float32 置信度/方差出现约 1e-7 舍入差异，记录在 `original_equivalence/coarse_shard0/equivalence.json`，不是所有原始匹配字段逐位一致。
- 新查询没有历史终点，使用 `--new-query-inference` 执行相同链，不能写作“数值复现旧结果”。
- 本轮首先补齐 StMarys 官方 530 张：seq13 四分片 350 张，加 seq3 98 张、seq5 82 张。seq10 88 张是历史开发序列，不加入官方 test 分母。
- 历史 seq13 已多次查看，不应称为全新的盲测。

## 必须保持的输入细节

旧官方 seq13 的 MoGe 是 resolution 5、FP16、先按 INTER_AREA 缩到 1024×576、refine steps 3；seq10 曾使用 resolution 9/FP32/原图，因此新的官方查询采用旧官方设置。

初始 RADIO 是 PIL BILINEAR、1024×576、原始 1280 维、batch 2。精细读出使用 PIL LANCZOS、1536×864 的投影 64 维特征。不能用后者缓存中的 coarse 数组代替前者。缓存复用核对配置和原图哈希。

各场景使用原生逐图内参及 SIMPLE_RADIAL 畸变，工作分辨率采用旧半像素缩放。GreatCourt 的训练图 seq5/frame00297.png 缺少原生相机绑定，清单明确记录；所有 1918 张官方测试图都有相机，不能隐式代用默认相机或删除测试图。

## 尚未完成，不能用简化实现代替的部分

其他四场景目前尚无与旧 StMarys 完整链对应的地图及拟合模型。旧 StMarys 的物理渲染表面依赖 source_index 清理掩码、学习式表面地图单元及其方向共识，不能拿简化原始高斯盘地图替换。当前仅找到 `/root/StMaryChurch2dgs_clean.ply`，其他四场景的同类清理文件及其原生成过程尚未找到。

仓库虽有 `run_goal_maplet_g23_strict_map_fold.sh` 和 `--clean_surface_elements` 建图路径，但不能将“把所有重建基元声明为 clean”当作原清理步骤的等价重现。跨场景训练还需保留原匹配头/验证器/局部选择器的训练协议，不得仅修改模型绑定的地图哈希来冒充适配。

因此完整特征准备、相机清单完成、旧查询等价重放均不等于五场景完整实验已完成。进度以各任务 `COMPLETE.json`、新查询终点及最终评估文件为准。

## 评估

`evaluate_stmarys_complete_test.py` 先检查两个种子各 530 个唯一预测、封存所有终点哈希，再读取测试位姿。汇报平均/中位数平移与旋转误差，以及 0.1m/1°、0.25m/2°、0.5m/5° 等召回率；失败保留在总分母内。五场景全部完成之前，报告显式保留 `five_scene_validation_complete=false`。

## 输入工具的实测复现证据

`output/cambridge_full_v417/original_equivalence/moge_raw_probe/equivalence.json`：旧 seq13/frame00001 和 frame00002 的 MoGe 点、深度、法线和掩码全部逐值一致；`plane_equivalence.json`：从这些新几何重新提取的平面标签、法线、偏移、支持像素数、RMS 和 P95 残差也全部逐值一致。

`output/cambridge_full_v417/moge_official_coverage.json` 确认其余四场景共 1388 张官方测试图的 MoGe 几何无遗漏、无重复，参数保持旧官方设置。这仍是输入准备证据，不是定位性能结果。
