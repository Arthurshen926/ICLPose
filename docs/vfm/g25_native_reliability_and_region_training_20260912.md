## 本轮结论

收益排序 32 是本轮较均衡的研究候选：相对上一轮固定细读出，严格召回持平，25cm 与 50cm 召回均提高 0.685 个百分点，平均旋转误差降低 0.01015°；平移均值只降低 1.74mm，置信区间跨零。不能称为大幅或全面稳定突破。

更强的归因证据是：相同全覆盖预算下条件学习优于固定系数；相同 32 更新预算下收益排序优于均匀选择。两项对照的平均平移与旋转改善在块长 5/10/20 的区间均不跨零。但该排序仍是坐标收益代理，不能据此声称已经学会最优地图单元。

全覆盖条件化虽降低总体中位数，却使严格召回从 30.14% 降到 29.22%。路线分解显示 seq10 严格召回从 30.68% 降至 26.14%，seq13 为 30.00% 持平；不能让总体平均掩盖路线退步。排序 32 也不是每路线严格召回都提升。两条路线的均值改善一致，1m/10° 与 2m/45° 召回均未改变，当前改进主要是局部精度与中等门限，未解决重大失败恢复。

## 实现与归因

- 学习六个无 GT 运行时特征到有界坐标校正系数，以及独立的正方差倍率；保留原生物理身份和原 token 范围。训练使用 20,409 条建图观测，按来源图像平衡。训练路线 seq1/2/4/6，留出 seq7/8/9/11。参数在查询评估前冻结。
- 留出建图像素误差：固定校准均值 1.273635、中位数 1.219178 px；条件化均值 1.249520、中位数 1.187031 px。Gaussian NLL 从 2.823821 降至 2.780786。此监督条件于可信可见身份，不是实际检索的匹配概率校准。
- mean 与 both 只区分方差；full 与 fixed_full 区分条件学习；rank32 与 uniform32 每个查询使用严格相同的更新数量。full 平均更新 120.97 个 token，原小覆盖 20.78 个，两个 32 配置均为 31.53 个。
- rank32 按 alpha²×原始位移平方排序，是坐标 MSE 收益代理。两组都先计算最多 128 个 token 的精特征，因此不是 ROI 计算节省，也不是已学习的区域集合位姿价值。
- 对应库存、世界坐标、相机、分数和初始位姿绑定通过审计。下游精修可重新选择观测，不能将固定库存表述为锁定最终优化行。

## 可学习区域：本轮完成与尚未完成

已生成 160 个建图查询、8 个按路线排除的原生区域库，每查询检索 16 个不同区域。基于当前 91,976 个原型构建上下文和成员，排除查询自身路线的来源。运行时数组匿名，来源仅保留在离线审计。160 张 RGB 的 MoGe 几何及有限平面已生成并逐文件验证来源绑定。
