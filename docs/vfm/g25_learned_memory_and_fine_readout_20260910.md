# G25：可学习地图单元与真实精细读出的完整受控实验

## 结论与实验边界

附件的三组核心受控实验现已落实：完整真实输入；固定／多尺度／建图阶段学习选择的记忆；最终层／中间层／真实高分辨率／选择性局部 ROI。此次补齐了可学习单元的实际地图产物、真实 RGB 重提取、亚 token 坐标对照、MoGe 相对深度验证，以及接入既有 MoGe 平面／尺度精修后的结果。

**有条件收益和明确的效率进展，但没有证据支持将完整自适应地图或高分辨率坐标修正直接升级为主线默认。** 最值得保留的是小容量稳定上下文、选择性 ROI 读出，以及身份读出与坐标读出分开的接口。学习单元尺度不是自动增益；区域描述子更好也不等于位姿更准。

所有新策略在 seq9 的 98 张建图留出图像上拟合，冻结后用于 seq12 的 188 张和 seq14 的 36 张图像。后两条路线不在当前外观 bank 中，但共享同一场景的几何地图，而且属于既有开发数据。重复种子不增加独立图像数。**本轮不是新场景盲测，也不是官方 438 图双分支、稀疏／稠密共识主线重跑。正式正确性基线仍是 96/330/398/409/412。**

这意味着“不同场景自动获得不同最佳地图单元”“优于所有显式／隐式表征”“已经获得完整的通用地图创新证据”仍不成立。没有其他场景的同协议 2DGS／chart／外观 bank，不能用更换几何底座的临时实验冒充跨场景对照。附件提出的这些论文成立条件，与已经完成的本场景方法试验必须区分。

## 1. 真正保存与学习了什么地图单元

几何保持 85554 个原型的原始世界坐标和平面身份。每个外观模式提供三种候选上下文，半径为 1、2、4 个粗 RADIO token，分别保存四方向、每方向 64 维的 float16 描述子。每种上下文关联该建图视角中被窗口覆盖的原始几何观测，最多保留 16 条引用。引用可跨平面，但不会改变任何世界坐标或平面方程。

共构造 **256662 个候选单元**。小、中、大窗口跨越多个物理平面的比例分别为 **25.19%、48.85%、77.23%**。这不是仅把一个 plane descriptor 更名为 memory：范围、上下文组成、关联几何行、存储选择均有明确产物。

首先对三种尺度分别训练关联读出，使用按图像二折的跨拟合分数，在 98 图上执行固定 PnP。每图使用全体候选及四个平面组，每组评分 256 个有限 AP3P 假设，保留 50% 均匀探索。三个尺度的五门限结果为：

| 尺度 | 0.1m/1° · 0.25m/2° · 0.5m/5° · 1m/10° · 2m/45° |
|---|---|
| 小 | 25 / 78 / 93 / 98 / 98 |
| 中 | 23 / 79 / 95 / 98 / 98 |
| 大 | 25 / 75 / 95 / 98 / 98 |

然后用静态地图属性预测单元效用：观测支撑、表面数、法向跨度、三维范围、跨视角描述子稳定性和模式数，以及它们的固定二阶组合。监督由有效身份、1.5px 精度效用、跨拟合关联置信度和实际 PnP 位姿效用组合而成。未知对应不自动进入负例。

学习结果选择 **31081 / 32390 / 22083** 个小／中／大单元。容量为 25% 时保留 **21388** 个增强单元，其尺度分布为 **3043 / 9808 / 8537**。选择结果在所有查询之前冻结，不按当前 query 的 GT 改图。

这实现的是一个定义明确的受容量约束、有限候选的地图策略：

\[
\hat V(u,s)=f_\theta(\text{map attributes}_{u,s}),\qquad
s_u=\arg\max_s\hat V(u,s),\qquad
\sum_u z_u\le B.
\]

当前回归目标是身份、观测精度与实际位姿表现的效用近似。它**不是**逐单元移除的因果贡献，也没有直接最小化整张地图的非凸 PnP 损失，更不能证明全局最优。固定后端结果进入监督，仍不能消除观测间相互作用带来的贡献分配误差；这是本轮学习器的理论和实验边界。

### 地图容量

所有尺度使用同样的四个 float16 描述子，完整增强描述子容量为 43803648 字节，25% 容量为 10950656 字节，约 **41.78 → 10.44 MiB**。固定上限的几何引用另需约 10.44 → 2.61 MiB。

这是**新增上下文存储减少 75%**，不是整个 2DGS／chart／基础外观地图减少 75%。地图文件另含用于核验的几何副本、索引与压缩开销，实际完整／25% 产物分别为 43748012／12674286 字节。全容量固定与自适应单元使用相同描述子数和比较数；小容量地图在不同查询中的命中数会不同，不能声称每图实际点积数严格相同。

## 3. RADIO：真正增加了什么信息

在相同原生 RGB 上重新提取粗分辨率控制，避免把不同预处理误差归为分辨率收益。

| 读出 | 实际输入与输出 | 角色 |
|---|---|---|
| 粗最终层控制 | 1024×576 RGB，36×64 token | 同预处理、同地图锚点的基准 |
| 中间层 | 相同粗 RGB，−6 层，固定 128 维正交随机投影 | 中间层身份信息；没有新增空间采样 |
| 高分辨率最终层 | 1536×864 RGB，54×96 token | 真实增加有效图像细节 |
| 局部 ROI 最终层 | 原生 960×540 象限 → 768×432，27×48 token | 一次只为选中的图像象限增加细节 |

所有实验使用同一 c-radio_v4-h checkpoint。地图锚点通过其建图相机投影到源 RGB，再取局部读出；query 不读取位姿、GT 或渲染深度。地图与查询采用一致的预处理、层和空间合同。中间层投影固定、不在验证图拟合；其结果只否决当前层和压缩读出，不代表所有中间特征无效。

完整重提取覆盖 1329 张 RGB，包括地图源和查询。选择性精细地图只为 21388 个增强单元保存额外描述子：64 维细特征约 **2.61 MiB**，128 维中间特征约 **5.22 MiB**。查询激活上限为 **128 个独立 token**；224 图中位数为 124.5。重叠单元和多个模式不会把一个 token 计成多票。

## 4. 真正的选择性 ROI：目前最明确的效率进展

地图只提取被选中单元需要的象限；每张 query 由已冻结的身份分数和单元选择确定一个象限。不是先跑完整高分辨率网络，再把其中一块称为 ROI。边界转换使用统一像素中心约定。

为分离“支持范围减少”和“改变特征上下文”，额外设置只使用相同 ROI 支持、但特征来自整图高分辨率的控制。

| 相同 ROI 支撑的身份读出 | PnP，种子 0 | PnP，种子 1 |
|---|---|---|
| 整图高分辨率特征 | 16/71/122/153/173 | 14/64/122/151/164 |
| 真正局部 RGB 提取 | 16/72/123/153/173 | 14/65/122/151/164 |

精修后分别为：

- 整图细特征：**16/77/132/155/175、15/75/136/155/167**。
- 真正局部 ROI：**16/78/133/155/175、15/76/136/155/167**。

两种子在 0.25m/2° 均多 1 张，收益很小，不能称为显著精度突破。其价值主要是保持相近定位表现时降低新增视觉推理成本。ROI 的直接亚 token 坐标改动反而退步，当前保留 ROI 身份读出，否决这一版 ROI 坐标修正。

相对固定中尺度精修控制，ROI 版本的 0.25m/2° 为 **76/75 → 78/76**，0.5m/5° 为 **129/133 → 133/136**；2m/45° 为 **174/168 → 175/167**。存在可重复的中等门限小幅收益，也存在粗门限退步，因此只作为可选效率工作点保留。

### 实测时间

同一 RTX 3090、模型常驻，10 张按固定规则选取的图像，每种形状预热，CUDA 同步计时：

| RADIO 读出 | 中位秒数 |
|---|---:|
| 粗最终层 | 0.1598 |
| 粗最终层＋中间层，共享一次前向 | 0.1618 |
| 额外整图高分辨率 | 0.7258 |
| 额外单个局部 ROI | 0.0809 |

新增高分辨率编码时间约降为 **1/9**；包含共同粗读出时，RADIO 部分约为 **0.886 → 0.241 秒**。ROI 输入像素为整图细输入的四分之一，Transformer 计算并非像素数的简单线性函数。

这些数值不含模型加载、MoGe 推理、召回、PnP 和精修，**不是完整定位系统端到端延迟**。本轮求解预算相同，但并行 CPU 运行的墙钟数也不适合拼成端到端延迟。当前没有集成成生产流水线，因此不据此宣称完整系统达到某个 FPS。

### 配对与分路线核验

ROI 相对固定中尺度精修，在 0.25m 门限两种子分别为 **5 改善／3 退步、5 改善／4 退步**，精确 McNemar p 为 **0.727、1.000**；0.5m 为 6/2、6/3，p 为 0.289、0.508。不能宣称统计显著。大量探索性对照也不支持挑选某个单门限未校正 p 值作为升级证据。

第一种子的中等门限增益来自 seq12，seq14 命中不变；第二种子 seq12／seq14 均有部分改善，但 seq12 的 2m 命中从 138 降至 137。总体中位平移误差为 **0.38214 → 0.37682m、0.37991 → 0.36367m**。逐路线结果和改善／退步配对均完整保留。

## 5. MoGe：保留成熟精修，否决新增顺序验证

新增软验证将预测相机下的锚点深度关系与 pose-free MoGe 局部关系比较：对数深度比抵消共同正尺度；仅在观察比值差异充分时使用前后顺序；每个邻接端点均衡贡献，不让密集区域和重复候选增加票数。没有硬深度拒绝，没有把 MoGe 当作绝对深度 GT。

在固定的五组胜出候选池中，深度顺序和比值都没有提高结果：

| 验证 | 种子 0 | 种子 1 |
|---|---|---|
| 原选择 | 16/71/122/155/172 | 13/65/121/151/164 |
| 深度顺序 | 16/70/121/155/172 | 13/64/121/151/164 |
| 相对深度比 | 16/71/121/155/172 | 13/64/120/151/163 |

本轮不继续扫描其系数。共同尺度不变性不能消除区域相关的 MoGe 形变，正确几何关系也不能挽救候选池中不存在的正确身份。

成熟的 MoGe 平面／尺度精修使用现有 `_refine_pose_scale` 函数，尺度由数据和弱先验联合估计。新适配器先保证一个 token 只选择一条观测，再以唯一 token 几何分数保护接受步骤。强平面关联要求至少 12/16 个观测像素属于同一区域，避免跨边界 token 被最后枚举的区域覆盖。

早期 `moge_*` 输出使用了未显式排除此边界歧义的适配器，已经被 **`moge_v2_*` 全量复跑取代**；本文和最终汇总只使用 v2。它仍不是正式主线的双坐标分支与最终稀疏／稠密共识。

## 6. 理论上现在能说什么

1. **地图单元可以学习，物理几何不必跟着变。** 单元是带上下文的固定锚定索引，世界点、平面、尺度与身份保持独立。重叠属于记忆组织，不能增加似然中的独立观测数。
2. **识别价值、局部坐标信息、整组位姿信息是不同量。** 较好的单条关联或重投影目标无法保证共享偏差减小，也不能保证整体几何条件改善。实际尺度学习结果说明，只用可解释属性回归单元效用仍有不足。
3. **特征分辨率增加提供观测，不保证正确读出。** 真实细坐标相对插值有条件优势，但不一定优于原坐标。稀疏采样、跨视角外观变化、地图锚点系统误差和错误实例仍可能主导最终精度。
4. **局部上下文与局部精定位应保持独立接口。** ROI 身份读出和 ROI 坐标更新的结果方向不同，证明不能把二者绑定为一个不可拆分升级。
5. **受生物启发的解释不能替代成立条件。** 稳定局部参照与相对位置编码是设计动机；本轮没有证明生物机制复现、通用最优地图单元或优于所有显式／隐式方法。

因此本轮形成了可验证的设计、算法、容量约束、坐标合同和负面结论；没有声称一般意义的理论最优性或已经完成跨场景论文证据。
