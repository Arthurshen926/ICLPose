# 新增对应歧义与全局提案：原生完整主线消融

本轮针对 8 区域前端的严格精度收益与粗定位/旋转退步，运行三组候选硬筛选与两组保留候选的全局提案对照。每组使用同一 438 查询和完整精修、稀疏/双稠密一致性选择。**五组完整验证已完成：硬筛选没有稳定整体优势；保留全部备选并替换全局提案得到更好的实测结果，但相对上一轮的增量区间仍跨零，尚不构成全面稳定升级。**

## 实现与实验范围

### 三种硬筛选

保留原主线的全部旧对应，对每个 token 最多保留一个**新增**假设：按 RADIO 余弦相似度、冻结坐标头的预测概率、随机选择。不是把整个库存限制为每 token 一个对应，旧多假设仍完整保留。

三组的新增 token 覆盖和保留行数完全一致。相对原 8 区域新增库存均减少约 21.70%；所有保留测量、原生世界坐标、原型身份与不确定度都是原库存的精确子集，没有修改坐标。随机种子由查询名称哈希确定，不依赖查询真值。

实现：`feature_extract/tools/vfm/filter_goal_maplet_native_region_augmentation.py`。三组政策在查看其位姿结果前冻结。

### 保留全部对应的全局提案

在硬筛选暴露退步后，追加两个探索性对照；这不是独立预注册验证。

- **token 抽样**：先均匀抽取四个不同 token，再从每个 token 的备选中均匀抽一条。
- **行抽样**：直接从规范化、去除完全重复假设后的对应行中抽四条，允许同一个 token 的不同候选进入样本。

仅替换“全部对应”这一个全局 PnP 提案。两组均使用 AP3P、相同唯一 token 评分和保护式局部精修，每查询固定评分 1000 个姿态假设，最多尝试 5000 次抽样。其余物理区域、原型和查询区域分组的候选逐数组复现原 8 区域版本，完整几何与选择后端不变。

这是**两种 AP3P 抽样策略之间的等评分预算对照**，不等于与历史 OpenCV EPNP 自适应 RANSAC 严格等计算。历史 1000 次最大迭代与当前 1000 个已评分模型不是同一预算定义。全局预算以 `global_proposal_*` 和实际 `scored_hypotheses` 为准，通用参考分组预算说明不能用来宣称全局求解器与历史版本等时。

实现参数：`evaluate_goal_maplet_direct_plane_pnp_multihypothesis.py` 的 `--global_proposal_sampler token/row`，默认 `cv`；现有 `token_hypothesis_ransac.py` 新增行抽样对照。全部候选保留，不使用筛选版本的对应。

## 初步机制诊断

新增对应在冻结后真实位姿下，满足正深度且 256×144 测量坐标系重投影误差不超过 4 px 的汇总比例：原 8 区域 37.03%，余弦筛选 44.05%，概率筛选 39.15%，随机筛选 39.36%。这是重投影一致率，不是稠密匹配真值准确率，也没有证明预测概率在新候选分布上完成了校准。

对应一致率上升不能保证位姿更好。余弦硬筛选的退步样例 `seq13__frame00136`，主分支平移误差由约 43 m 增至约 586 m；公共稀疏验证缺少足够关联，而备用位姿也约有 96 m 误差。它同时涉及候选/提案质量和验证证据不足，不是仅凭换一个最终选择规则就能恢复正确定位。

本轮没有根据该样例设置专用阈值、删除查询，或将有限位姿输出视为定位成功。当前工作应区分：避免重复投票、分配抽样概率、提前删除物理身份备选，三者不是同一个操作。

## 最终结果

全查询中位数和召回率均使用全部 438 查询。下表带星号的均值使用固定的 436 查询公共有效子集，包含历史区域基线共同有效条件，便于与前两轮比较。单个阶段报告可能使用 437 查询的公共有效子集；本节所有比较统一来自 `combined_metrics.json`，位姿本身没有更改。

token-AP3P 相对原 8 区域的条件平均平移误差由 0.8729 m 降至 0.7238 m，平移中位误差由 0.1452 m 降至 0.1431 m，严格召回率增加 1.14 个百分点。row-AP3P 的条件平均平移/旋转误差更低，但严格召回率低于 token-AP3P。二者的 0.5 m / 5° 召回率均比原 8 区域低 0.46 个百分点，不能称为无退步升级。

### 统计范围与因果边界

3000 次配对循环轨迹块 bootstrap，seq13 分片恢复时间顺序，块长为 5/10/20。相对原 8 区域，两个全局提案的条件均值、中位数和严格召回增量区间均跨零。块长 10 下，token-AP3P 的条件平均平移误差差值区间为 [-0.527,+0.066] m，严格召回差值区间为 [-1.37,+3.65] 个百分点；row-AP3P 的条件平均平移误差差值区间为 [-0.706,+0.003] m。

token-AP3P 相对更早 4 区域前端的严格召回差值为 +4.79 个百分点，三个块长的区间均高于零；但这同时包含先前扩大区域检索的贡献，不能全部归功于本轮抽样改动。token 与 row 的直接差异也未建立稳定优势，不能声称独立 token 抽样必然更好。

本轮结果提示应保留后续几何消歧的机会。硬筛选同时改变候选覆盖和抽样路径，当前不能将退步全部归因于正确对应被删除。冻结全部备选时，只改变全局提案即可改变完整位姿结果。AP3P、固定评分预算及抽样策略相对于旧 OpenCV 后端同时发生变化，因此其贡献尚未完全拆分。当前保留两种全局提案为可复现候选配置，默认仍为 `cv`，没有据单轮开发集结果替换默认。
