# Overlap 作用位置与 LoD 批量展开：v403

本轮承接 v402，目标是把共有区域学习与身份解码分开，核查少量支撑门槛，以及消除 LoD Python 展开开销。结果目录为 `output/g25_pose_transport/planar_map_rendered_ransac_v1/surface_coordinate_upgrade_v1/` 下的 `overlap_isolation_v403`、`overlap_weighted_v403`、`overlap_weighted_seed2_v403`。下文简称 B 下对应目录。

## 实现及控制变量

继续冻结 v402 修正后的 overlap 网络、MNN 身份、原始地图、细网格坐标与精修/验证器，不追加测试集训练或阈值搜索。438 查询使用相同 LoD 提案、每区域 250 假设预算及固定 RANSAC 种子。

1. `overlap_mnn`：原 MNN 对应经过校准 overlap ≥ 0.5 硬过滤，保留单位采样权重。用于隔离 overlap 删除对应的作用。
2. `weighted_mnn` 的正式软采样：保留原 MNN 全部对应；50% 均匀探索，50% 按每个 token 的 overlap 概率选择互不重复的 token，再选其身份。源码新策略名为 `overlap_prior`。
3. 原 `context_prior` 只在同 token 内按身份权重采样。在 MNN 单身份情况下，overlap 权重不会改变结果。本轮发现并修正此机制适配问题；`overlap_isolation_v403` 中名为 `weighted_mnn` 的输出属于无效权重对照，其位姿与 v402 MNN 逐位一致，不能作为新的有效方法。正式软采样结果放在独立的 `overlap_weighted_v403`，没有覆盖对照。

实现上对 token 权重使用该 token 各模式的最大值，避免重复模式增加 token 的采样质量；采样不放回，保留均匀探索。这只保证低分 token 仍有采样机会，不保证预测准确或有限预算一定找到正确位姿。没有把候选 GT 用于采样或接受。

## 硬过滤为什么失败

固定身份后，硬过滤仍使精修 25 cm/2° 从 77.85% 降为 64.84%，50 cm/5° 从 89.73% 降为 81.96%。平移中位误差 0.144→0.171 m；旋转中位误差 0.456→0.552°。这表明 v402 的退化不能只归因于学习 identity 解码。

事后 GT 投影诊断：硬过滤平均保留 58.33% 的原 token，以及 71.15% 的几何正确 token。这里“几何正确”仅指正相机深度、重投影≤4 coarse pixels，未使用独立可见性真值；对无正代理查询不定义正 token 保留率。平均值是逐查询比率均值，不是所有对应的池化比例。它支持当前网络提高纯度时损失了关键覆盖，但不证明全部被删除 token 都是真实共有区域。

因此 overlap 二分类阈值适合度不应只通过精确率判断，应结合保留的正确支撑覆盖与最终位姿。当前监督仍是渲染代理，unknown 很多，mapping 与 query 条件也存在差异。本轮没有通过调低测试集阈值修饰结果。

## 第二种子：召回收益尚不稳定

第二种子确认：软采样精修平移均值/中位数为 0.599/0.142 m，旋转为 1.865/0.456°，10/25/50 cm 召回为 28.77/74.89/89.04%；同种子 v402 MNN 为 29.68/77.63/91.32%。首种子的精修召回优势没有复现。最终模式读出为平移 0.614/0.108 m、旋转 1.967/0.350°，10/25/50 cm 召回 47.03/88.13/94.06%，同种子旧分支为 47.03/88.58/94.52%。因此软采样目前只是有正例的实验分支，不构成稳定提升；两个种子也不足以估计统计显著性。不能选择性地只报首种子。

## 少量支撑门槛诊断

审计 v402 已完成候选中“评分优于基线、6≤支撑数<24”的提案，不改变实际接受规则。LoD＋MNN 该集合 50 cm 召回为 0%，平移中位误差 7.81 m；LoD＋学习匹配器为 6.67%，平移中位误差 2.38 m。两者 25 cm 召回均为 0%。这不排除今后更好的少量支撑验证器，但说明当前提案上直接取消数量门槛没有依据。

诊断只覆盖已有候选池，不能证明被 32 支撑精修门槛跳过的正确候选不存在；也不能代替带不确定性及几何条件的验证。该新验证器、可观测性驱动支撑选择和更可靠身份监督仍未完成。

## LoD 批量展开：确定性效率收益

将逐 token 对多外观代表的全排序改为批量分组最大值，再选父/子区域，保留同样的 stable tie 顺序和局部直接旁路。L2 锚点读出及原几何保持不变。

全部 438 查询验证了区域提案、展开叶集合和描述子比较数与旧实现完全相同。另有带外观分数平局的参考实现测试。该改动没有引入新的精度/检索取舍。

独立 20 个 mapping seq7 查询，同次比较、交替顺序、各三次重复取中位数后平均：平铺最近邻 52.63 ms，优化 LoD 34.40 ms，耗时约降低 34.6%。精确 atlas 行 top1 一致率仍为 57.77%，与旧 LoD 相同。上轮与本轮机器负载不同，不能把跨轮绝对耗时直接相减；本轮的平铺/LoD 相对对照才是依据。

这是缓存 CPU 搜索算子测试，不包含 RGB 编码、重建、磁盘加载或完整定位链路。全局 L1 扫描仍存在，不声称 O(log N) 或大场景流式系统已完成。

## 工程检查与后续边界

31 项相关测试通过，包括新 token 级采样的作用、均匀探索保留、无重复 token、LoD 平局一致性和原匹配/RANSAC 测试。源代码快照和脚本位于 `overlap_isolation_v403/sources` 与 `reproducers`。实验输出分开保存，旧无效权重对照明确保留；没有更改第三方子模块。

本轮结论应限定为：当前 overlap 不适合硬删除，作为搜索先验有单次收益但尚不稳定；LoD 展开实现已在不改变结果的情况下提速。学习身份、遮挡塔尖恢复、可学习地图成员/边界、独立场景及投稿级置信度验证还没有完成。保留原强基线，后续优先改善监督与可观测性，而非继续在测试集上扫描筛选阈值。
