## 2. 当前实际流程

不能把历轮所有实验拼成一张“已经全部联合训练”的模型。当前有共享几何底座、完整历史主线，以及受控实验分支。

### 离线建图与监督

1. 建图 RGB、已知相机与 metric 2DGS 建立米制表面，有限平面/chart 负责局部几何参数化和原型坐标。平面仍用于测量，但不必限定记忆组织边界。
2. RADIO 产生外观特征，地图保存匿名外观模式/局部原型与几何引用。上下文实验另读出方向排列、多尺度窗口；其开销属于新增外观存储。
3. 完整 MoGe 输入先形成区域与候选，再独立附加可靠、歧义或 unknown 监督。多视角渲染一致性补充部分 unknown。补充的是同一地图派生的伪监督，不是独立传感器真值；未知项不能当负例。
4. 可学习组织层在建图侧冻结：早期版本选择图像上下文尺度及存储位置；最新版本固定 123 个物理中心，学习每个中心的 3/6/9m 半径，并保存其真实原型成员。成员数引用总和受固定 6m 基线容量上限约束，世界坐标不变化。

### 查询时

1. RGB 提取 RADIO 外观和 MoGe 局部几何，进入原有检索/对应生成与坐标读出，得到图像测量—三维原型候选。
2. 可选的上下文或相对几何读出重排已有候选；精细 RADIO ROI 可以提供更细像素读出。它们均有实验，但不是全部默认开启。
3. 根据候选中的独立 query token 支撑激活部分物理区域，区域成员形成 PnP 种子组。重叠区域不能让同一 token 重复增加支持票数。
4. 生成和验证位姿假设，再执行相应协议的几何精修与选解，输出米制 SE(3) 相机位姿。

最关键的未完成接口：当前物理记忆层主要重新组织**已经生成的候选**。还没有完成“先检索整个区域，再通过区域内部视觉/三维配置生成新对应”的独立前端。因此若正确物理身份已经在候选生成阶段缺失，后续换边界通常无法补回它。

## 4. 理论上还缺什么

### 任务目标与实际部署尚不一致

完整目标应围绕最终位姿和部署成本，例如：

\[
\min_{M,\theta}\;\mathbb E_{q\sim\mathcal D}\big[\ell(T_\theta(q;M),T_q^*)\big],\quad
C_{\rm bytes}(M)\le B_m,\quad C_{\rm online}(q,M)\le B_q.
\]

其中 M 含区域成员、上下文描述子和几何引用；T 应包含实际激活、对应生成、假设选择及后端。此式是建议明确的设计目标，不是声称当前代码已经求解它；损失也需预先规定平移/旋转尺度与失败代价，不能事后按最好召回门限选方案。

当前目标只用 98 张单路线建图查询、1211 个采样图像—中心组合，覆盖约一半中心；训练未包括完整 MoGe、所有部署分组和全部可激活区域，随机种子的索引方式也不同。把单区域效用改成集合 max，仅优化“池中存在好解”；考虑选择器后有所改善，但依然不是部署全流程目标。

### 集合互补还没有完整刻画

独立高分区域可能看到同一批 token 或同一退化几何。理想单元价值应依赖已选集合：是否新增独立证据、改善位姿约束、减少身份歧义。当前 max 代理只部分反映冗余，不反映完整跨区域联合求解；局部预算交换没有全局最优保证。不能把这一代理的训练上升当成最终召回必然上升的证明。

### 可辨识性与可观测性需要分开

一个区域纹理丰富，并不保证它属于正确物理实例；重复窗户可提供很多互相一致的错误匹配。反过来，身份正确的局部窄区域也可能对部分位姿方向约束弱。应分别测“正确物理区域能否被辨认”和“其测量能否稳定约束相机六自由度”。

在线性化、对应正确及噪声模型合适的局部条件下，可以用重投影雅可比构造 H=JᵀWJ，检查小特征值/条件数，作为几何约束诊断。它不是全局定位正确性的证明，也不能用内点数量替代。当前尚缺把这种可观测性和身份消歧联合纳入记忆选择的受控验证。

### 不确定性与相关误差尚未统一

同一 RADIO token、同一局部表面或同一伪监督源的误差可能相关。唯一 token 去重修复重复计票，但并未解决相邻坐标的共同偏差、MoGe 局部形变和共享地图误差。现有 uncertainty/几何保护也不能等同于一个经过校准的完整相关噪声模型。更低逐点坐标误差不必然形成更低整图位姿误差。

### 表征自由度和理论主张应匹配

当前学习的是固定中心上的离散球形支持半径。尚未学习中心、区域数量、任意形状、独立点级成员以及跨场景规则。所有基础地图和全局候选仍保留，不能宣称“仅存少数记忆点即可定位”。

“稳定的局部参照＋上下文＋相对位姿”可作为设计动机；本次没有新增生物学验证。仿生类比不能证明优于显式/隐式方法，也不能把纯隐式方法一概等同于全局位姿回归。论文真正缺的是清楚的学习对象、可部署的效用目标、同成本比较与独立泛化证据，而非更强的命名。

## 5. RADIO / MoGe 是否还有余力，性能空间有多大

不能认定基础特征已被充分利用。已有方向排列、相对几何读出改善关联指标，说明旧读出遗漏过信息；改变现有候选的几何组织也能改善结果。但这两点均不能量化“还有多少最终位姿收益”。

- RADIO：当前上下文多用于已有候选评分，尚缺区域整体身份检索和部分可见配置匹配。真实高分辨率、中间层与插值对照已做，但有限层/投影和有限 ROI 实验不能否定其他读出方式。其增量与坐标头、视角变化和精修契合程度有关。
- MoGe：已用法向、局部形状、深度顺序/比值以及平面/尺度精修；尚未完整实现可靠度感知的局部关系配置匹配。相对量减轻共同尺度依赖，但不自动修复局部形变或全部重复结构歧义。
- 后端：低平均误差和高严格召回是不同目标。当前均值受大失败影响，严格召回依然明显不足；应分别评价失败恢复与亚像素/坐标一致性，不能把修复单例的均值收益当成严格精度进展。

因此，“仍有值得验证的改进空间”有证据；“一定还有很大提升”没有定量证据。当前候选池 oracle 也只能说明给定候选池和后端的潜力，不能作为 RADIO/MoGe 的能力上限。

最有价值的后续顺序：

1. **对齐学习与部署。** 完整可激活区域池、多种子、完整后端效用、多建图路线；先保持当前有限边界族，检查是否稳定超过固定及打乱控制。
2. **让区域进入前端。** 独立区域检索＋局部配置部分匹配，保留原几何身份；检验能否找回原先缺失的正确对应，而不只重排同一池。
3. **针对严格精度读出。** 在冻结上述选择的条件下，比较匹配的地图/query 精细读出与粗插值，检查整图共同坐标偏差及实际延迟。
4. **扩大自由度前完成泛化。** 增加独立路线/场景和完整存储、在线耗时对照；再判断任意成员 mask、中心或区域数量学习是否值得。
