## 结论与处理

本轮没有获得优于上一轮排序32配置的完整主线方案，因此不更新默认配置。原生上下文8改善部分宽门限但严格召回退步；学习第9区域相对按检索添加的严格召回提高3.425pp，却损失25cm/50cm召回并引入无效输出；最多新token对照的均值也退步。不能把建图诊断的提升表述为查询主线提升。

正面进展是首次真正训练了相对已有集合的位姿增益，且建图留出上的中位数与25/50cm召回在三个种子下方向一致。其向混合前端的直接迁移失败，说明训练目标与运行前端一致性比增加学习器复杂度更紧迫；这不是可学习地图单元没有意义的证据。

retrieval9和learned9均在seq13__frame00142.png.npz初始PnP阶段没有可用位姿，后续均无效；无效率0.2283%，所以全样本均值为∞。native8对此查询为17.25m/116.97°，简单回退只能恢复有限输出，不能算正确定位恢复。没有通过回退或剔除该样本包装均值。

建议下一轮先生成同折原平面前端，与区域候选并集后按真实1024新增上限和实际求姿预算生成监督。集合特征应衡量相对原平面前端及已选区域的增量，而非仅相对8个区域；同时记录加入后的竞争、初值失败和停止价值。独立确认集与完整成本账仍需同步补齐。

## 本轮实际学习了什么

对固定检索集合 S（前8区域），分别冻结 S 和 S∪{r} 的 token-AP3P 位姿，r 为检索排名9到16。所有推理产物封存后才打开建图位姿监督。目标为 ΔU=U(T(S∪{r}))−U(T(S))，其中 U=exp(−平移误差/0.5−旋转误差/5)，无效位姿取0。允许负增益，不假设加区域单调有益。

13个无真值特征包括新增token覆盖、与已有集合重叠、匹配响应、上下文覆盖增量、到已有中心的距离和图像分布。标准化与ridge系数仅在seq1/2/4/6的80张建图图像拟合；seq7/8/9/11共80张留出。每查询有8个候选，训练按查询等权。没有用seq10/13位姿拟合。

与上一轮仅有候选库不同，本轮已实际生成1440组初始位姿反事实、训练权重，并接入原生区域增广器进行完整求姿。反事实训练是区域前端单独运行、256评分假设预算；运行时是含原平面前端的完整系统、1000全局评分假设预算。这一分布差异是明确的局限。
