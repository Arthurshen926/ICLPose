KEY STATISTICS:

Architecture:
  - Total Parameters: 4.48M (lightweight)
  - Decoders: 0.80M (18%)
  - Flow Heads: 2.72M (61% of total)
  - Context modules: 0.96M (21%)

Memory (Float32):
  - Per Sample (BS=1): 2.5 MB
  - Batch Size 4: 10.2 MB
  - Batch Size 8: 20.4 MB
  - Fine level: 68% of total

Compute:
  - Fine level: 80% of forward pass
  - Coarse + Mid: 20% combined
  - Geometry solver: ~5% (not critical path)

Resolutions:
  - Coarse: 7×10 (70 pixels)
  - Mid: 1520 (300 pixels)
  - Fine: 35×46 (1,610 pixels)
  - exp050 Fine: 60×80 (4,800 pixels)

OPTIMIZATION OPPORTUNITIES:

Quick Wins (No Retraining):
  • fine_iters 4→8: +0.3° accuracy, 2× compute
  • outer_iters 3→5: +0.3° accuracy, +67% rendering
  • batch_size 4→8: Better gradients, linear memory
  • gamma 0.8→0.95: +0.1° accuracy, no cost

NOT Recommended:
  ❌ decode_dim 64→128: +1MB memory, ~0° benefit
  ❌ hidden_dim reduction: Risks convergence
  ❌ local_radius change: Affects patterns

To Break Accuracy Floor:
  → exp050 recipe: fine_hw=[60,80], BS=2
  → +1.0° accuracy improvement
  → Requires 4× memory
