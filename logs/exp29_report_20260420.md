# Exp29 Report

Date: 2026-04-20
Scene: OldHospital
Goal: test whether learned `center + frustum` proposals are more suitable than direct pose regression for render-based refinement.

## Common setup

- Features: `output/feature_extract/features_radio_dual_128/OldHospital_pilot`
- Patch tokens only for new runs unless noted: `feat=both`
- Pooling: `attn`
- Patch dim: `128`
- Epochs: `10000`
- Batch size: `128`
- Optimizer: `AdamW(lr=1e-3, wd=1e-4)`

## Experiments

### Exp29a: no-summary direct regression baseline

Command summary:

`python feature_retrieval/patch_regressor_v7.py --pool attn --feat both --attn_heads 4 --hidden_dims 2048 1024 512 --dropout 0.15 --feature_dropout 0.15 --patch_dim 128 --epochs 10000 --batch_size 128 --seed 123 --exp_name exp29a_direct_both_seed123`

Results:

- Direct median: `1.83 deg / 1407 mm`
- Direct `R@5deg/1m = 33.5%`
- Direct `R@10deg/2m = 57.1%`
- Retrieval median: `11.05 deg / 2693 mm`
- Retrieval `R@10deg/2m = 19.8%`

Takeaway:

- Removing summary helps.
- This is a stronger single-model baseline than current `center/frustum` variants.

### Exp29b: center + frustum, 32 anchors

Command summary:

`python feature_retrieval/patch_center_frustum_v1.py --pool attn --feat both --attn_heads 4 --hidden_dims 2048 1024 512 --rot_hidden_dims 1024 512 --patch_dim 128 --n_anchors 32 --center_mode mixture --center_topk 3 --epochs 10000 --batch_size 128 --seed 123 --exp_name exp29b_center_frustum_both_k32_seed123`

Results:

- Direct median: `2.97 deg / 2722 mm`
- Direct `R@5deg/1m = 14.8%`
- Direct `R@10deg/2m = 34.1%`
- Retrieval median: `11.14 deg / 3235 mm`
- Retrieval `R@10deg/2m = 20.9%`
- Anchor top-1 acc: about `68.7%`
- Anchor top-3 acc: about `89.0%`

Takeaway:

- Better matched to the desired factorization, but current implementation is far weaker than direct regression.

### Exp29c: center + frustum v2, 64 anchors

Changes:

- residual normalization added
- `center_topk=5`

Results:

- Direct median: `3.15 deg / 3114 mm`
- Direct `R@10deg/2m = 35.2%`
- Retrieval `R@10deg/2m = 15.4%`
- Anchor top-1 acc: about `42.3%`
- Anchor top-3 acc: about `63.2%`

Takeaway:

- More anchors hurt anchor classification and did not improve final pose.

### Exp29d: center + frustum v2, 128 anchors

Results:

- Direct median: `3.48 deg / 3329 mm`
- Direct `R@10deg/2m = 35.2%`
- Retrieval `R@10deg/2m = 18.7%`
- Anchor top-1 acc: about `33.5%`
- Anchor top-3 acc: about `55.5%`

Takeaway:

- Increasing anchor count further degrades anchor prediction quality.

## Current conclusion

- `patch-token no-summary direct regression` is the strongest current single-model initializer.
- Current `center + frustum` implementation is not yet competitive.
- The likely issue is not the factorization itself, but that the current model is still optimizing for single pose prediction rather than `top-k proposal quality` for downstream refinement.
- Next direction: redesign `center/frustum` as a true proposal generator and evaluate by top-k oracle / post-refine metrics, not only direct top-1 pose.
